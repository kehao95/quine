# system-coherence

Keep operational descriptions usable with the code and evidence they refer to.
When behavior changes, update the instructions and interfaces that rely on it.

Different theories or accounts can disagree. Make the disagreement legible and
retain the observations or arguments that would help examine it. Coherence in
a working interface and agreement about the whole project are different needs.
