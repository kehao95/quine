# amendment-protocol

Instructions and procedures are working material. Revise them when a task,
new idea, recurring difficulty, or changed understanding calls for it.

Describe the reason for a substantive change and update the paths that use it.
Remove rules that no longer serve the work. Keep concrete setup knowledge with
its operational owner, where future participants can find it.

This protocol can itself be revised. Use [theory](../Paper/theory/README.md)
for conceptual development and [DEVELOPMENT](../DEVELOPMENT.md) for implementation
and relevant checks. Preserve the user's instructions and actual access and
publication boundaries.
