# Principles

These working principles are public. Some research and tooling references
remain outside the [public release scope](../development/PUBLIC-RELEASE.md).

This directory contains Quine's working operating-principle objects and three
thematic navigation views over them. Normative content remains in the individual
principle objects; views group links without becoming a second authority.

---

## Thematic views

Use these views to enter the object set at a useful conceptual grain:

| View | Focus & Scope | Canonical objects routed |
| :--- | :--- | :--- |
| [`scientific-grounding.md`](./scientific-grounding.md) | **Epistemic Posture & Discovery** | Active inference, evidence before rhetoric, exploration before compression, discovery invariants, transport validation, reproducibility. |
| [`system-architecture.md`](./system-architecture.md) | **Architecture & Maintenance** | Self-production, working coherence, single canonical location, boundary objects, structuralization, automation typology, control planes, boundedness, artifact lifecycle. |
| [`operational-evolution.md`](./operational-evolution.md) | **Self-Model Evolution & Reflection** | Descriptive vs. normative discipline, incremental change, traceability, amendment protocol, reflexive capture, failure modes, encoder collision. |

---

## Architectural boundary

The individual objects preserve stable link targets and independent revision.
The three views reduce cold-start navigation cost. Use them to find the relevant guidance; revise its source when the work changes.
