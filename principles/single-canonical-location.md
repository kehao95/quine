# single-canonical-location

Give mutable operational facts, schemas, and procedures a clear source so that
consumers can find the current version. Generate or link repeated operational
views where that avoids synchronization work.

Different interpretations can draw on the same material and remain distinct.
Cross-link related accounts where useful; preserve the differences that make
each worth reading.
