# absorption-rule

Leave useful work in a findable place with enough context to resume it.
An unresolved idea, discarded approach, or discussion can be retained for the
questions and alternatives it carries. Operational decisions belong with the
code or procedure that uses them.

Remove disposable scaffolding when its purpose has ended. Retention and
integration follow [CLOSURE](../CLOSURE.md); turning a discussion into one
settled conclusion is not required to preserve it.
