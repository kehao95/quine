# Evolution Arc Index

> Evidence index for the repository self-model and structural evolution control plane. This file extracts
> representative structural arcs from [`../EVOLUTION.md`](../EVOLUTION.md)
> and recent committed repository-self-model repairs so the theory can read the
> repository's history as developmental evidence, not only as a chronological
> log.

## Purpose

The repository-self-model theory treats control-plane evolution as evidence.
`EVOLUTION.md` is the canonical chronological journal; recent commits may appear
here before the journal is next refreshed. This index is a thematic projection
for asking:

```text
friction -> named defect -> owning layer -> repair surface -> perception shift
```

Use this index when developing `structure-grows`, refining the
repository-self-model theory map, maintaining EVOLUTION, or selecting examples
of structure/perception co-evolution. Do not treat this as a replacement for `EVOLUTION.md`; it is a
retrieval layer over it.

## Cross-Arc Patterns

### 1. Container friction precedes organ differentiation

A surface starts by carrying multiple jobs because the system does not yet know
which distinctions matter. Friction appears as oversized READMEs, live/archive
confusion, or paper dossiers holding theory that is not paper-local. Durable
repair splits the surface only after the overloaded jobs are visible.

### 2. Perception infrastructure grows after blind spots hurt

The repo rarely invents validators or journals in the abstract. It grows them
after repeated drift, stale assumptions, or retrieval failure show that human
memory is insufficient. The perception organ is therefore downstream of a real
blind spot.

### 3. Rollback can be positive developmental evidence

The self-source layout rollback is not merely failure cleanup. It is evidence
that the repo can test a structural hypothesis against substrate reality,
reject the wrong morphology, and preserve the learned constraint.

### 4. Projection boundaries prevent false compression

Several arcs separate layers that had been collapsing into one another:
theme vs paper, runtime philosophy vs implementation contract, normative
direction vs paper claim, exploration vs public defensibility. This is a
central repository-self-model pattern: coherence improves by preserving layer
specificity, not by flattening everything into one safe statement.

### 5. Activation surfaces turn expectations into behavior

A rule becomes more causally coupled when it moves from expectation to entry
condition, hook, validator, template, or explicit protocol. The `Maintenance`
keyword and causal map are examples: they make a desired behavior easier to
invoke and inspect.

## Evidence Payoff For Repository-Self-Model Theory

These arcs support five live theoretical readings:

1. **Repository as developmental system** - history shows morphology changing in
   response to pressure, not just files accumulating.
2. **Friction as metabolic pressure** - repeated workarounds become the energy
   source for structural repair.
3. **Control-plane evolution as evidence** - the most important changes are often
   to routing, ownership, validation, and self-description, not only code.
4. **Perception and structure co-evolve** - new structure exposes new drift;
   new drift demands sharper structure.
5. **Human-bounded artificial self-maintenance** - Human correction remains a
   boundary signal, but durable repair reduces dependence on repeated Human
   intervention.

## Gaps This Index Reveals

- Several arcs still lack explicit before/after behavior evidence; future
  entries should record how the repair changed subsequent agent behavior when
  observable.
- Human correction is still mostly chat-local unless immediately absorbed into a
  control-plane doc.
- Machine perception is strong for shape, links, ownership, and metadata, but
  still weak for semantic layer confusion and premature compression.
- The V0 living-runtime spine arc is now historical: later control-plane repair
  retired it as a roadmap frame because it over-compressed process control,
  world projection, experiment-local habitat, and self-maintenance behavior.
  Future arc entries should name layer boundaries explicitly instead of
  reviving the spine as a current acceptance target.
