# The Autopoietic Repository

**Subtitle:** Strange Loops, Entropy, and the System That Rewrites Itself

## Current Question

How do we explain the repository itself as a self-modifying, self-maintaining system without turning one essay into the umbrella theory for every Quine claim?

## Thesis

When AI agents become first-class collaborators in a code repository, the repository stops being a passive archive and starts becoming an autopoietic system—one that maintains and modifies its own existence rules through self-referential loops. This essay traces that transformation through concrete Git history, from early chaos to a system that designs its own adversarial tests.

## In Scope

- the strange-loop (Hofstadter/GEB) framing of repository self-modification
- thermodynamic perspective: entropy management, friction as signal, sustainable coherence
- the concrete repo evolution (Constitution, Testing Protocol, Closure Protocol) as evidence
- the L3→L4 testing leap as proof of autopoiesis (from instruction-following to emergent behavior)
- an outward-facing explanation for technically sophisticated readers

## Out Of Scope

- full paper-level proof of Quine's systems or A-Life claims
- exhaustive repo history or every AGENTS.md evolution step
- turning one post into the umbrella explanation for every Quine concept
