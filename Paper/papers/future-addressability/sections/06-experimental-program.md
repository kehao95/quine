# Experimental Program

Future addressability becomes useful when it separates outcomes that would
otherwise be conflated. The next experiments should not merely ask whether a
successor exists. They should ask which carrier makes the successor continuous,
which organization is sufficient, and which scaffold is doing the work.

| Test | Primary distinction | Result A | Result B |
|---|---|---|---|
| `6F.01` Minimal non-Quine `ctl/wake` adapter | Quine runtime versus control-compatible organization | adapter succeeds, so the self-object is abstract control-surface compatibility | adapter fails while rebuilt Quine succeeds, so runtime organization matters |
| `6F.02` Successor-mission ablation | control-surface closure versus continuation-contract compliance | closure survives weaker successor mission | closure depends on explicit mission scaffold |
| `6F.03` Multi-wake closure | one delayed task versus restored receptive organization | repeated wake/action/report/idle succeeds | first wake succeeds but receptive condition degrades |
| `6F.04` Carrier perturbation | passive continuity versus adaptive carrier repair | successor diagnoses and repairs damaged carrier | successor loses addressability or misroutes output |
| `6F.05` Checkpoint/restart contrast | state preservation versus organizational reconstruction | saved state dominates continuity | carrier and role reconstruction dominate continuity |
| `6F.06` Source degradation/repair | passive self-description versus active reconstruction | successor repairs partial source before handoff | source damage breaks rebuild |
| `6F.07` Actor/mailbox analog | Quine-specific result versus general carrier-indexed continuity | mailbox-bound roles show the same criterion | Quine remains a special process-native case |
| `6F.08` Multi-generation recursion | one-step closure versus lineage-level continuity | closure repeats across generations | error, drift, or scaffold dependence accumulates |

Status note: `6F.07` now has a first deterministic mailbox wave
(`evidence-set:6F.07-first-mailbox-analog-wave-20260628`) supporting Result A
for the tested analog: preserved role mailboxes pass while new-mailbox /
address-lost controls fail.

The most discriminating first experiment is the minimal non-Quine `ctl/wake`
adapter. It tests whether Quine's positive control-surface case selected the
Quine runtime specifically or any organization implementing the relevant
control-surface trace. Either result is theoretically useful. Success moves the
claim upward to "control-surface-compatible organization." Failure supports
the narrower claim that Quine's runtime organization is currently the viable
self-object in this ecology.

The second priority is successor-mission ablation. The current evidence is
bounded because the successor receives a continuation contract. Removing or
weakening instructions to stay alive, call `idle`, treat control payloads as
tasks, use tools, and return to `idle` would map the scaffold gradient.

The third priority is multi-wake closure. A single post-handoff wake establishes
delayed addressability. Repeated wakes test whether the successor restored a
stable receptive organization or only survived a one-shot probe.

Every experiment should report:

- the boundary event crossed
- the carrier through which the later obligation arrived
- whether the later obligation was unseen before the boundary
- the future-obligation trace
- whether the receptive condition was restored
- scaffold dependencies: source, toolchain, provider, runtime, probe, mission
- failure mode, especially state drift, substrate capture, irreversible
  degradation, or unbounded recursion

This reporting discipline is more important than any single positive result.
It prevents body copying, source rebuild, state restoration, endpoint naming,
and future addressability from being collapsed into one success bit.
