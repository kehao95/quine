# Context

We have an experimental result showing that AI agent successor form varies with "material" (what information crosses a process-death barrier) × "demand" (what task the successor must satisfy). We want to formalize this using concepts from evolutionary developmental biology (evo-devo): reaction norms, phenotypic plasticity, canalization, genetic assimilation, Waddington's epigenetic landscape.

# Research questions

1. Has anyone applied developmental reaction norms (Via & Lande 1985), canalization, or Waddington's epigenetic landscape to AI agents, LLMs, neural networks, or computational self-reproduction?

2. Has anyone used catastrophe theory (René Thom) to model discontinuous transitions in software agent behavior or AI system morphology?

3. Has anyone applied Kauffman boolean networks or random Boolean network attractors to model distinct operational states of AI agents or software systems?

4. Has anyone tested "genetic assimilation" (Waddington 1953) in AI — plastic behavioral traits becoming hardcoded through repeated training/selection?

5. Has anyone used the concept of "phenotypic accommodation" (West-Eberhard 2003) to describe how AI systems reroute their architecture when partially degraded?

6. Has anyone drawn the specific analogy: AI model weights = genotype, runtime environment = environment, agent behavior = phenotype, and studied the reaction norm (G×E interaction)?

7. What is the state of "artificial development" — applying developmental biology principles to AI/ML systems?

# Scope
- 2018-2025 for AI-specific work
- Any date for foundational evo-devo/biology work if directly cited
- Include ALife, computational biology, and AI/ML venues

# Output
For each question: yes/no + specific papers with arxiv IDs or DOIs + 1-sentence assessment of how close the prior work is to our direction.
