# Context

We are writing a paper on AI self-replication that may take one of two framings:
- Framing A (theory): showing that existing benchmarks compress multiple independent dimensions into one operating point
- Framing B (empirical): demonstrating an existence proof of replication-like succession under conditions where standard replication assumptions are violated (no source access, no individual continuity, no explicit replication goal, no full function preservation)

For Framing B, we need to know if anyone has ALREADY demonstrated or claimed to demonstrate AI replication-like behavior under non-standard conditions. We also need to know what formal/information-theoretic arguments exist for conditional non-inheritance of agent properties.

# Research questions

1. Has anyone demonstrated AI agent replication/successor formation WITHOUT source access?
   - Reconstruction from partial information (weights only? config only? behavior only?)
   - Successor formation through operational environment reconstruction
   - Any "replication without copying" claims

2. Has anyone demonstrated AI agent replication WITHOUT explicit replication instructions?
   - Incidental proliferation
   - Emergent copying behavior
   - Task-driven delegation that becomes lineage-like

3. Has anyone used information-theoretic arguments about AI agent property preservation?
   - Channel capacity for agent replication
   - Rate-distortion for agent fidelity
   - Data processing inequality applied to agent reconstruction
   - Mutual information between predecessor and successor
   - Any formal bound on what can be reconstructed from partial descriptions

4. Has anyone formulated a CONDITIONAL non-inheritance theorem for AI agents?
   - "If property X is not in channel Y, and criterion Z doesn't test X, then X is not reliably inherited"
   - Any formal statement connecting heritability channel to criterion aperture

5. What is the formal landscape for AI agent replication theory?
   - Mathematical models of AI replication
   - Formal verification of replication properties
   - Any axiomatic or logical treatment
   - Connection to von Neumann self-reproduction formalism

6. Has anyone explicitly argued that standard self-replication conditions (source access, individual continuity, replication goal, functional equivalence) are NOT NECESSARY for replication-like continuation?
   - Existence proofs or counterexamples
   - Relaxed definitions of replication/succession
   - "Near-replication" or "approximate replication" concepts

# Scope

- Formal/theoretical AI work: any date
- Empirical demonstrations: 2022-2025
- Information theory applied to AI/agents: any date
- Von Neumann self-reproduction and successors: foundational works
- Philosophy of identity/continuity applied to AI: any date

# Deliverables

1. Literature map for each research question
2. Explicit list of any prior existence proofs or counterexamples
3. Formal arguments found (information-theoretic, logical, game-theoretic)
4. Assessment: what has been proven vs. what remains open
5. Closest prior work to our conditional non-inheritance argument

# Output requirements

Structured markdown with:
- Executive summary
- Literature map by question
- Formal arguments inventory (with exact statements where possible)
- Prior existence proofs / counterexamples
- Novelty assessment for our specific claims
- Key references with URLs/arxiv IDs
