# Figures

This directory holds the figure pairings for the manifesto.

Current figure surfaces:

1. `runtime-architecture.svg` and `runtime-architecture.png` - the runtime-stack overview used to show the OS-as-runtime argument
2. `io-contract.svg` and `io-contract.png` - the input/output contract diagram used to show the process-style execution model

Format convention:

- `.svg` is the primary editable source and preferred manuscript target
- `.png` is the raster companion for preview or distribution surfaces that prefer bitmap assets
- paired files should share the same stem so the figure set stays mechanically obvious
