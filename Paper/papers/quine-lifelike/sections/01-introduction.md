# Introduction

Artificial Life asks what life-like organization could be in other media, not only how biological life works as we know it \citep{Langton1989ArtificialLife,Beer2024ALifeAsItCouldBe}. A substrate advances that program when it turns questions about persistence, adaptation, and organization into tractable interventions. Historically, classic digital-organism systems such as Tierra and Avida established this synthetic approach by making self-replicating programs experimentally accessible \citep{Ray1992SynthesisOfLife,OfriaWilke2004Avida}. More recent LLM-based ecologies have begun studying survival, reproduction, and persistent artifacts in simulated worlds \citep{PaoloEtAl2026TerraLingua,MasumoriIkegami2025SurvivalInstinctSugarscape}. Across both lines, however, a methodological gap remains: mortality, environmental persistence, and maintenance are often tightly coupled in the physics, only rhetorically described, or fixed by world design \citep{Bedau2003ArtificialLifeReview,McMullin2004ThirtyYearsComputationalAutopoiesis}. What is still missing is a medium in which these pressures are all real and experimentally separable.

This paper addresses that gap using Quine, a process-native computational lineage in which each individual is a native UNIX process rather than a framework-managed agent object \citep{Ke2026Quine}. In most agent frameworks, lifecycle, reset, and memory-retention semantics are imposed by an application-level orchestrator. In Quine, the individual boundary coincides with the process boundary, so isolation, death, volatile memory loss, and post-exit persistence are host-enforced habitat facts rather than orchestration conventions. Classic digital ecologies already treated computation as a genuine ecological medium whose scheduler rules, resource allocation, and memory constraints functioned as world physics \citep{Ray1992SynthesisOfLife,OfriaWilke2004Avida}. Quine's contribution is different in kind: because death, isolation, volatile-memory loss, and durable persistence are enforced by the operating-system kernel rather than by application-level policy, they cannot be circumvented by an implementation loophole. Native processhood therefore makes these pressures into independently perturbable habitat variables whose causal attribution is secured by the substrate itself, so lineage-level organization can be tested by intervention rather than only described by analogy.

Methodologically, Quine treats identity-through-time as persistence of organized activity rather than of static substance \citep{NicholsonDupre2018EverythingFlows,Pradeu2018GenidentityBiologicalProcesses}. The scientific payoff is concrete: in one medium, we can block continuity paths while preserving durable state, wipe persistence while keeping the same lineage task, or vary maintenance pressure while keeping the same affordance surface.

We validate this claim with three pressure-sensitive contrasts. Each contrast holds the task and capability surface fixed while varying one habitat condition, so any organizational difference can be attributed to the manipulated pressure rather than to capability or prompt variation. When a continuity path is available, real death recruits lineage persistence; when it is blocked, the same pressure yields single-life collapse. Persistent writable habitat recruits environmental cognitive organs through predecessor-modified traces; wiped or read-only habitat collapses that organization, and same-habitat controls show that writable persistence alone is not enough. Stronger maintenance pressure recruits more decoupled post-exit maintenance structures than neutral one-shot framing alone. Taken together, the three results are not independent discoveries but a coordinated test of one methodological claim: that viability pressures in a process-native medium are separable enough to recruit and collapse specific life-like organizations by intervention.
