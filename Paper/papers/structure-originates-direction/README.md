## Methodological Grounding & Core Finding

Environmental structure operates as an **originating directional force and action-licensing mechanism** that can be factorially manipulated with matched controls on a frozen, task-free, reward-free LLM agent in a real software workspace (filesystem, tools, execution), scored by externally-verified functional dependent variables.

While prior literature either imposed an explicit task or substituted an artificial drive (metabolism or survival penalty), our preparation demonstrates that environmental structure alone originates coherent, functional agent trajectories and selectively licenses action.


## Current Question

Can static workspace features direct frozen, task-free, reward-free LLM agents
toward specific externally verified actions, beyond serving as passive context?

## Thesis

The paper claims that the environment is a behavior source for frozen LLM
agents: workspace structure can steer action selection without task wording or
reward. The claim is bounded to observed structural-elicitation motifs and the
additional ICLR upgrade experiments.

## In Scope

- Five structural feature kinds and their matched controls.
- Harness-generality, selection-steering, and feature-competition upgrades.
- A counterfactual framing: static workspace composition changes agent action.

## Out Of Scope

- A claim that structure creates agency from nothing.
- A proof that the effect is independent of all latent model priors.
- The two-latch mechanism paper, except as a companion boundary.

## Claim

**The environment is a behavior source — not merely context.** For a
frozen-weight LLM agent with no task and no reward, static workspace
features reliably *drive* specific, externally-verified functional acts that
matched controls never produce (96/102 vs 0/85, three model families).
"Direction comes from the environment" in the **counterfactual** sense:
change the feature and the act changes; remove it and the act never occurs.
The paper's core exhibit is **five kinds of environmental features that pull
agent behavior** — rupture, gap, topology, semantic collision, executable
affordance. Scope is deliberately the **dynamics layer only** (the geometry
layer — five kinematic meta-dimensions — is explicitly out of scope, future
work). Full statement, the "not claimed" boundary, and the sharpened novelty
contrast live in [`plans/claim.md`](plans/claim.md) — the canonical, editable claim.

## Positioning (see `plans/claim.md` § "Why this is novel" for the full version)

One load-bearing contrast: **fields that study LLM agents treat the
environment as passive (context/information/constraint/harness); we show it
is active — a behavior source.** Primary foil: LLM-agent / context
engineering. Secondary: RL/UED (effect without weight updates or reward);
the nudge line (Cherep et al.: PNAS 2026 = arXiv 2505.11584, one work, PNAS
canonical; plus ABxLab, arXiv 2509.25609 — message-like human-derived
nudges on tasked agents, risk register; ours are bare workspace conditions
on task-free agents, positive-design register). Supporting neighbors rather
than opponents: situated/distributed cognition, ecological psychology
(Withagen; Rietveld), Barker behavior-settings, stigmergy — traditions that
already grant environments a behavior-shaping role; the contribution is the
demonstration for frozen, deliberative LLM agents with matched pairs and
un-fakeable DVs.
