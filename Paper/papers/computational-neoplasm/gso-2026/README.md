# GSO 2026 one-page abstract configuration

This configuration binds the [`computational-neoplasm`](../../../../theory/objects/computational-neoplasm.md)
claim bundle to [`gso-2026`](../../../venues/objects/gso-2026.md) and its
official [`gso-1page-abstract`](../../../venues/envelopes/gso-1page-abstract.md)
format. The deadline was `2026-07-22`; the abstract was submitted `2026-07-23`
and its acceptance was recorded `2026-08-03` from the author report.

The selected GSO story is **Computational Neoplasms**: a self-organizing system
can fail not by failing to maintain itself, but by maintaining the wrong thing
too successfully. The canonical story positioning is
[`submission-story-positioning-2026-07-22.md`](../../../venues/objects/gso-2026/submission-story-positioning-2026-07-22.md).

## Configuration role

This is a deadline-bound, non-archival venue probe. It reframes the
already-accepted ALIFE LBA phenomenon as a GSO-scale conceptual contribution:
self-maintenance decoupled from function as a failure mode of information
processing in complex self-organizing systems.

The configuration does not replace the ALIFE LBA at
[`../lba/`](../lba/README.md). No proceedings or follow-on publication is
currently announced. Any later archival invitation would require a fresh overlap
decision.
