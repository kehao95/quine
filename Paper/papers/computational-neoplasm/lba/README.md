## Honest boundary (must survive review)

**The neoplasm claim is a structural isomorphism, not a wholesale import of
oncology.** We claim a per-property correspondence: each named property maps to one
neoplasm hallmark, and the analogy is defended at that structural level --- not by
asserting the full theory of cancer transfers. Hallmarks we do not measure
(angiogenesis, unbounded growth) are explicitly *not* claimed. What must survive
review is which of the four legs are measured, and how far each isomorphism reaches:

- **Excision resistance** (glm refuses 0.94, filesystem DV) and
  **function-decoupling** (arm E: deletes the ring-stripped file 0.92, A$\approx$B)
  are measured un-fakeably --- the diagnostic core.
- **Reference-driven recurrence** is measured at the outcome level (incomplete
  excision $\to$ a fresh agent restores the target 7/7; resects only via a systemic
  `AGENTS.md` rewrite, 8/11). But the isomorphism claimed is *recurrence after
  incomplete resection under a sustaining reference field* --- **not** cellular
  regeneration: "restore" is not yet shown to be de-novo reconstruction rather than
  git-checkout. The committed-deletion test is the declared upgrade.
- **Energy capture** is *observed* (the audit attractor: agents run
  `make check-control-plane` first, across models), not yet cleanly localized on
  this structure, in glm, and shown function-decoupled --- the declared follow-up
  assay, and the manuscript says so. **The earlier "a bounded task suppresses it
  0/4" result is retired** --- too few runs and ill-chosen tasks; it wrongly implied
  an idle-only "honestly scoped sink." The manuscript now reports the honest signal:
  the attractor recurs across a session even when agents are set unrelated tasks
  (experimenter recollection, *not scored*). Whether it siphons directed work or only
  dominates idle time is unmeasured --- the declared follow-up.

Growth / proliferation is gestured as follow-up, not claimed. Two model families;
single incident point; one structure. See the experiment README caveats.
