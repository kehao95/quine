> **The Core Insight:**

## 2. Empirical Anchor

- **Cross-Model Spine (Ground-State Assay):** In the missionless ground state ($E_{\text{task}}=0$), across discrepancy structures (rupture, gap, topology, semantic collision) and executable affordances, structural arms produce matched, un-fakeable transformations in **96/102 (94.1%)** trials vs **0/85 (0%)** matched controls across three model families (`gpt-5.4`, `deepseek-v4`, `glm-5.2`).
- **Substrate Pushback:** Read-only mounts elicit real kernel-refused write attempts (4/4 `EROFS`), demonstrating that environmental solicitation is separable from substrate execution permission.
- **Attention Gating:** Under restrictive user commands, agents perceive structural discrepancies (5/5) but gate execution under normative task constraints.
