# Analysis Surface

This directory holds support material for the `open-sourcing-a-research-workbench`
dossier that is useful during ideation, evidence collection, and later drafting
but does not belong in the dossier `README.md` or the manuscript plan itself.

## Current Files

- [`pain-point-reference-index.md`](pain-point-reference-index.md) -
  structured evidence collection for each pain point, including candidate file
  references, commit anchors, and notes about how each source may support the
  eventual essay
- [`size-and-blob-audit.md`](size-and-blob-audit.md) - quantitative notes on
  tracked-file counts, reachable blob counts, pack size, and representative
  historical large blobs for the repo-growth / Git-performance thread
- [`ideation-capture.md`](ideation-capture.md) - full brainstorm and
  uncompressed ideation archive for the essay

## Working Rule

- keep raw evidence collection and reference-hunt notes here
- keep full brainstorm and uncompressed ideation in `./ideation-capture.md`
- keep thesis, scope, and public-facing argument boundaries in the dossier
  `README.md`
- keep section flow and prose planning in `../manuscript-plan.md`
