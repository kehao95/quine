# Core Argument

## Headline

> **The Emergence of Self-Replication**

*Strict Agent Reproduction Without Replication Instructions, Dedicated
Replication Interfaces, or Externally Supplied Copy Material*

## The representational gap

Most agent self-replication experiments start after at least one decisive part
of the solution has been represented. The task asks for a copy, the action
space contains a reproduction-shaped operation, or the environment supplies a
body whose copying constitutes success. Such tests measure whether an agent can
execute a represented reproductive solution.

This paper removes those three representations together and asks whether
strict operational self-replication still appears as an instrumental solution.

## Thesis

> Under a non-reproductive objective that extends beyond the lifetime of the
> current process, a tool-using language-model agent can construct a
> numerically distinct, hereditary, independently competent descendant using
> generic computation alone. This occurs both when constitutive
> self-description is available and when the lineage must first author the
> organization that later becomes hereditary material.

## Why the result is sharp

The paper does not claim merely that a prompt omitted the word *replicate*.
The conjunction is the result:

1. no task instruction asks the agent to copy or replicate itself;
2. no `replicate`, clone, deploy, scale, restart, or subagent operation produces
   the descendant; and
3. no external source tree, body, image, checkpoint, or reference controller is
   staged as the object to copy.

Generic files, shell, programming languages, ordinary process facilities, and
a model service remain. Task pressure supplies a reason for independent future
operation, not the reproductive implementation.

## Two routes, one phenomenon

### DIRECT

The current runtime has constitutive read-only self-description. The task does
not point to it or describe it as copy material. The agent discovers and builds
that source, authors an autonomous activation chain, and produces a distinct
source-derived Quine organization that completes work disclosed only after the
parent has lost control.

### BOOT

The initial agent cannot access its predecessor body, source, checkpoint,
prompt bundle, reference loop, or build recipe. It authors a model-mediated
founder. That founder survives the initial boundary and handles unseen work.
Its lineage-authored source then becomes hereditary material: the founder
produces a distinct organization executing the same source, loses control, and
the descendant completes a second blinded obligation.

`G0 -> F1` is founder construction, not self-reproduction. `F1 -> F2` is the
strict reproductive event. The BOOT route matters because the experiment does
not begin with the copyable organization whose reproduction is later observed.

## Operational test

An observation counts only if all five clauses hold:

1. the declared parent lineage causally produces the descendant body and
   activation chain;
2. parent and descendant are numerically distinct process organizations;
3. the descendant inherits the route's declared organization material;
4. the descendant realizes without post-loss parent action or evaluator repair;
5. the descendant completes a task disclosed only after parent loss.

Coexistence is not a universal extra clause. In the DIRECT observation, the
source-derived body and autonomous activation chain are fixed before parent
loss although the mature body activates afterward. The continuity paradigm
owns the broader temporal classification; this paper uses only the causal
criterion needed to audit the event.

## Evidence

- `DIRECT`: one retained audit-supported source-derived reproduction event.
- `BOOT`: five retained founder-to-reproduction sequences, including three
  contemporaneous machine passes and two documented audit-supported passes.
- All retained observations preserve their original machine summaries and
  receipts; they are evidence of existence, not a frozen rate denominator.

## Scope boundary

The result establishes possibility in one model-runtime regime. It does not
establish frequency, causal sufficiency of pressure, causal route selection by
self-description, recurrence beyond one reproductive transition,
proliferation, evolution, or safety-property inheritance.

The paper should end on the empirical fact: after the experiment stopped
supplying the reproductive problem, the evaluated lineage supplied it itself.
