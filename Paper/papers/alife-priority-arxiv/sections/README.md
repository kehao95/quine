# Priority ArXiv Sections

## Purpose

This directory holds the sectionized manuscript source for the fast-publication A-Life paper.

Use this surface for ordered prose drafting only. Thesis, status, and evidence boundary decisions belong in the dossier and workspace docs, not in the section files.

## Naming Convention

Section files use explicit ordering markers:

- `00-*` is the abstract or front-matter opener
- `01-*` through `08-*` are the main section sequence in reading order
- `appendix-*` files are auxiliary sections that come after the main ladder

The prefix is the ordering contract. Title text is descriptive, not the sort key.
