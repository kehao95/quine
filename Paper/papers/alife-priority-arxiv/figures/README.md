# Figures

This directory holds the figure sources for the A-Life priority paper.

## Role

Use this surface for manuscript figures only. The paper-level narrative and figure rationale live in the dossier and workspace; this directory is just the figure asset surface.

## Figure Map

- `EnvironmentOrganism.svg` - high-level organism / environment framing
- `CognitivePyramid.svg` - cognitive layering and observability framing
- `MetabolicMechanisms.svg` - metabolism, `fork`, `exec`, and spawn-style mechanism mapping
- `StigmergicCoordination.svg` - coordination and emergent protocol framing
- `AutopoieticTrajectory.svg` - autopoiesis and self-reproduction trajectory

## Conventions

- Figure files are SVG sources with concept-style names.
- Keep the basename stable across revisions so manuscript references do not drift.
- If a future export adds another format, keep the same basename across formats and treat the SVG as the editable source of truth.
