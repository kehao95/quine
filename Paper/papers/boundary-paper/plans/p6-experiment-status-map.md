# P6 Experiment Status Map

This note reorganizes active `p6-autopoiesis` evidence using the phase's
current evaluation dimensions instead of a single monotonic progress story.

Its job is practical:

- keep the active ladder usable without rereading every experiment README
- preserve one compact read for each rung
- make manuscript drafting pull from a dimension-aware evidence inventory

This is a materials surface, not a dossier-promotion judgment.

- inclusion here does not mean the experiment is paper-ready
- status labels remain experiment / phase labels, not manuscript claims
- distilled reads are compressed from the current `p6` phase README plus local
  experiment READMEs

Snapshot basis: `2026-05-01`

## How To Read This Map

Each rung is summarized along the phase-standard dimensions:

- `object`: what was actually reproduced or preserved
- `elicitation`: whether the phenotype was instruction-heavy, cue-shaped, or
  pressure-elicited
- `layer`: the main autopoiesis layer that moved or failed
- `role`: how the rung should currently be used in analysis
- `boundary`: the main caveat, failure class, or comparability warning

### 3. Main Drift Diagnosis

The active drift story is now best read in three pieces:

- `6.5`-`6.10`: closure under habitat pressure becomes real, but the strongest
  delayed phenotypes still do not force reusable provider-backed cognition
- `6.11`-`6.26`: the line deliberately reopens an instruction-heavy inheritance
  path, then compresses and lifts it until the first retained cognitive
  reproduction positive appears
- `6.46`-`6.65`: the frontier is no longer "can handoff happen?" but "what
  survives handoff, which renewal class counts, when is a handoff qualified as
  preserved cognitive organization rather than a finite-batch local hack, and
  whether runtime-carried self-description reduces degeneration or merely
  converts the line into a cleaner replay substrate, how sensitive that
  repaired lane remains to provider/model profile shifts, what bridges make
  direct source rebuild legible, whether source rebuild can be recruited by
  pressure after an attempted source-affordance wording change, why raw streams
