## Query Protocol Routing

If you need a new deep research prompt rather than a read of existing results:

- shared paper-side workflow:
  [`../../../research.md`](../../../research.md)
- active reusable paper-local briefs should live in
  [`../plans/README.md`](../plans/README.md)
- this `references/` surface is the paper-local archive owner after a query set
  has already been run and absorbed

Use this directory to recover:

- prior query wording
- absorbed report copies
- paper-local provenance for the absorbed query set

Do not treat this directory as the place to author a fresh reusable brief by
default; new durable briefs should start in `plans/` and later be absorbed here
only if the query set is consolidated into archival reference material.

Use them to identify:

- which claims are likely safe
- which literatures matter
- which citations should be verified next
- which overclaims to avoid

Do **not** cite the reports' internal citation tokens directly in the paper.
Manuscript prose should cite verified primary sources instead.
