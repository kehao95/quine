## Editorial Defaults

- lead with agreement on the problem before naming Quine's divergence
- use `harness -> habitat` only when the concrete process / file / IO /
  permission / namespace / signal / IPC substrate is visible nearby
- keep the piece blog-readable: one central contrast, then concrete mechanism
  mappings
- avoid turning the post into a survey or a manifesto
- keep examples such as anchor memory, overlay worlds, and `ctl` surfaces as
  current probes, not doctrine
