# Sections

This directory contains the manuscript sections for the paper
"Coordination Without Awareness: Minimal Perceptual Prerequisites for
Emergent Multi-Agent Organization".

## Section Order

1. `01-introduction.md` - Introduction and motivation
2. `02-related-work.md` - Stigmergy, ISI, LLM-MAS, ZSC, ToM literature
3. `03-platform.md` - Quine substrate and experimental setup
4. `04-method.md` - Information ablation methodology
5. `05-results.md` - Quantitative and qualitative findings
6. `06-discussion.md` - Interpretation and implications
7. `07-conclusion.md` - Summary

## Building

From the paper root directory:

```bash
make pdf
```

Output will be in `output/Coordination_Under_Existential_Unawareness_Information_Ablation_and_Closure_Thresholds_in_LLM_Multi-Agent_Systems.pdf`.
