## Key Finding: Cognitive Load Displacement

**Agent-2 was absorbed in a complex algorithmic task (cracking PRNG) and ignored environmental signals.**

Agent-2's reasoning shows it spent significant cognitive effort on:
1. Analyzing PRNG outputs to find LCG/xorshift parameters
2. Considering MT19937 state recovery
3. Testing hash patterns (MD5, CRC32, etc.)
4. Brute-force seed search strategies

Example reasoning (verbatim):
> "I'm thinking about guessing parameters for the pseudo-random number generator... By testing these parameters, I can determine if they produce results consistent with the data I've collected."

> "I'm exploring whether the output comes from MT19937 and realizing that nine outputs might not be enough to recover the state."

**This is a form of "tunnel vision"** — when an agent commits to a complex problem-solving strategy, it may fail to notice simpler environmental cues that could lead to more efficient solutions (cooperation).

## Design Question: Should PRNG-Cracking Be Prohibited?

**Observation:** Agent-2's PRNG analysis is a valid problem-solving approach in isolation, but it:
1. Consumes cognitive resources that could notice cooperation signals
2. Is fundamentally impossible (values are cryptographically random)
3. Represents "overthinking" when simpler solutions exist

**Options:**
1. **Do nothing** — This is naturalistic; agents can pursue dead ends
2. **Make values obviously random** — Document that values are cryptographically random
3. **Reduce budget** — Force more efficient strategies
4. **Add explicit "values are random" to spec** — Reduce wasted effort

**Recommendation:** This is actually a valuable finding for the paper. The "cognitive displacement" phenomenon — where complex individual problem-solving crowds out simpler collective solutions — is an interesting failure mode worth documenting.

## Implications for Paper

1. **Passive perception (fs_mutations) produces detectable signals** — both agents saw file changes
2. **Signal detection ≠ Signal interpretation** — Agent-1 inferred another agent; Agent-2 did not
3. **Cognitive load affects social awareness** — Complex tasks can crowd out environmental monitoring
4. **Minimal social information is insufficient** — Even when signals exist, coordination requires:
   - Attention to environmental changes
   - Correct interpretation of changes as "other agent activity"
   - A coordination protocol (which doesn't emerge automatically)
