# 6M.07 Aggregate Morphology Metrics

**Experiment ID:** `6M.07`
**Type:** analysis / metric-cleanup
**Status:** analysis generated
**Parent lineage:** `6M.01`--`6M.10`

## Question

Can the first `6M` wave be normalized into a paper-facing morphology table
without overstating quantitative precision?

## Theory Role

`6M.01`--`6M.10` now support a categorical trace-level morphospace read.
`6M.07` turns those retained outcomes into a stable analysis surface before the
computational-morphogenesis paper uses counts, figures, or metric language.

The governing relation is:

```text
future-carrier demand × viability-depth × self-description material/degradation
  -> successor morphology class
  -> post-handoff viability depth or failure mode
```

## Planned Output Table

Generated files:

```text
experiments/analysis/6m-morphology-records.csv
experiments/analysis/6m-morphology-summary.md
```

Required fields:

- experiment and condition;
- run identifier / evidence-set handle;
- self-description material and degradation mode;
- future-carrier demand;
- required viability depth;
- successor morphology class;
- implementation thickness notes;
- process relation and real-handoff marker;
- addressability depth;
- proof / competence depth;
- readiness recovery depth;
- generated files / LOC when artifact-backed;
- artifact size;
- build attempts / repair loops when artifact-backed;
- pre-handoff versus post-handoff tool calls when artifact-backed;
- failure class or `none`;
- `unknown` fields explicitly marked.
