# The Autopoietic Repository

> Strange Loops, Entropy, and the System That Rewrites Itself. A blog essay — published on Substack.

This entry is the self-contained public record of the essay: the manuscript
source and its figures, alongside the canonical published version.

**Read it:** <https://kehao95.substack.com/p/the-autopoietic-repository>

## What it's about

The flagship essay of the repository-self-model line. When AI agents become
first-class collaborators, a repository stops being a filing cabinet and becomes
something closer to a lab — an autopoietic system that maintains and modifies its
own rules. It follows the strange loop of a repository that writes its own
self-model into a file and hands it to stateless agents to enact, session after
session.
