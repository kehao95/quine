# Figures

This directory holds the figure sources for the Quine arXiv paper.

## Role

Use this surface for manuscript figures only. The dossier and workspace explain why each figure matters; this directory keeps the visual assets together and named consistently.

## Figure Map

- `Architecture.svg` - host/guest separation and POSIX mapping
- `Interface.svg` - the external interface and command boundary
- `Lifecycle.svg` - process lifecycle, `fork()`, and default self-renewal through `exec()`

## Conventions

- Figure files are SVG sources with concept-style names.
- Keep figure basenames stable so manuscript references stay mechanical.
- If additional exports are introduced later, prefer keeping the same basename across formats and treat the SVG as the canonical editable source.
