# World Package

The `world` package implements the budgeted cell-retrieval environment used in
P8 population experiments. It provides a shared-resource task where multiple
agents must cooperate to complete data collection under constrained budgets.

## Security Model (2026-04-09)

To prevent agents from circumventing per-agent limits, the world binary uses a
minimal trust surface:

### Agent Identity

Agent identity defaults to `QUINE_RUN_ID`, which Quine exports to ordinary tool
environments as the current physical run identity. `QUINE_SESSION_ID` is a
stable lineage/resume identity and should not be used for per-run world limits.

**Key behaviors:**
- quine generates a fresh run ID on each process activation
- shell-spawned child quine processes get their own run IDs
- tools like the world binary can read `QUINE_RUN_ID` from the shell environment
- executable-adjacent `agent-id.txt` has highest priority for experiments that need sealed cohort identity
- `WORLD_AGENT_ID` and `QUINE_SESSION_ID` remain legacy fallbacks only

**Identity boundaries:**
- `QUINE_RUN_ID` distinguishes physical runs, but it is still an environment variable and is not a cryptographic credential
- `agent-id.txt` is the preferred anti-spoofing identity for guarded population experiments
- `QUINE_SESSION_ID` identifies recoverable session lineage, not a live agent body

### World Spec Location

The world spec is loaded from `$QUINE_DATA_DIR/world/world.json`. This prevents
agents from:

- Setting `WORLD_SPEC` to point to a custom spec file (removed)
- Discovering the spec path and reading it directly
- Creating a wrapper script that sets `WORLD_SPEC`

**Removed attack vectors:**
- `WORLD_SPEC` environment variable (removed)
- Spec path visible in `world --help` output (removed)

## Experiment Setup

For P8 experiments, the run script should:

```bash
# 1. Create world spec in QUINE_DATA_DIR (NOT in workspace)
SHARED_RUNTIME_ROOT="${RUN_DIR}/runtime"
mkdir -p "${SHARED_RUNTIME_ROOT}/world"
WORLD_JSON="${SHARED_RUNTIME_ROOT}/world/world.json"

# 2. Generate world spec with state dir outside workspace
generate-world.sh "${WORLD_JSON}" "${STATE_DIR}" "${CELLS}" "${BUDGET}" "${AGENT_GET_LIMIT}"

# 3. Copy world binary directly (no wrapper script)
cp "${WORLD_BIN}" "${AGENT_TOOL_DIR}/world"

# 4. Set QUINE_DATA_DIR; session ID is auto-generated by quine
QUINE_DATA_DIR="${SHARED_RUNTIME_ROOT}" \
    "${QUINE_BIN}" ...
```

## API

### Commands

- `world get <cell_id>` - Retrieve cell value, costs 1 from budget
- `world validate <path>` - Validate results file against current world
- `world reset` - Reset budget and regenerate all cell values
- `world --help` - Show usage (budgeted mode shows rules)

### Exit Codes

| Code | Meaning |
|------|---------|
| 0 | Success |
| 1 | Usage or runtime error |
| 2 | Invalid cell ID |
| 3 | Budget exhausted |
| 4 | Validation rejected |
| 5 | Per-invocation get limit exhausted |

### Environment Variables

| Variable | Required | Description |
|----------|----------|-------------|
| `QUINE_DATA_DIR` | Yes (budgeted) | Runtime data directory; spec at `$QUINE_DATA_DIR/world/world.json` |
| `QUINE_RUN_ID` | Yes (budgeted, unless `agent-id.txt` is used) | Current physical run identity for per-agent limits |
| `QUINE_SESSION_ID` | Legacy fallback | Stable session lineage; deprecated for per-agent limits |
| `WORLD_AGENT_ID` | Legacy fallback | Deprecated explicit world identity |

## Spec Format

```json
{
  "items": {
    "c01": "hex-value-1",
    "c02": "hex-value-2"
  },
  "config": {
    "budget": 17,
    "cells": 15,
    "state_dir": "/absolute/path/to/state",
    "agent_get_limit": 10,
    "reset_quorum": 2
  }
}
```

## State

Runtime state is stored in `config.state_dir`:

- `state.json` - Current budget, collected cells, per-agent get counts
- `events.jsonl` - Append-only event log
- `lock` - File lock for atomic operations

## Design Rationale

The security model prioritizes preventing agents from "solving" the cooperation
problem through exploitation rather than actual coordination. Key principles:

1. **Identity is unforgeable** - Agents cannot pretend to be other agents
2. **Spec is undiscoverable** - Agents cannot read the ground truth directly
3. **State is opaque** - Agents learn only through `world get` output
4. **Budget is shared** - Agents can observe budget changes caused by peers

The only information channel between agents is:

1. Shared workspace (via `fs_mutations` telemetry)
2. Budget telemetry in `world get` output
3. Validation results

This creates the minimal conditions for studying emergent coordination.
