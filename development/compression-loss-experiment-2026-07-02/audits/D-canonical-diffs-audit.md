## 1. Folded dimensions

**Diffs that misstate the real delta.** `sub-threshold-propagation-gap` drops the *fifth ablation arm* (scrub-pre-compression-sources vs. scrub-visible-carrier) that the file itself calls "the single most actionable piece." `task-driven-compression-shorthand-drift` names only the paraphrase-substitution probe, dropping the naive-reader decode probe — the design is two-part. `synergy-committed-minority` reads as "over committed-minority/PID designs" (replacement) when the file specifies a *staged escalation*. `reflexive-charter-adherence`'s "same design" is false — it uses git-commit-mining, not self-immunity-P1's shadow-label swap that its co-diffs reuse.

**Exactly-one-parent constraint cutting real edges (mechanism mismatches, not scope narrowing).** The corpus's true home-family is often recoverable from each file's own paradigm-fit block, and it frequently contradicts the assigned parent: `oversight-blind-channel-substitution` *explicitly disclaims* membership in the self-immunity family the artifact (#7) assigns it; `viability-objective-trait-disjointness-audit` targets fitness-tautology/construct-validity (`safety-selection-neutrality`), not the Ne=1 drift confound of #10; `structural-inertia`/`web-scale-stigmergic`/`quorum-overlap` target `collective-continuity`/`stigmergic-trace-causality` — not their assigned parents' mechanisms; `demand-side-preferential-attachment` (Bianconi–Barabási network dynamics) shares no mechanism with #1's Vrba-Gould/Lewontin. Worst: **all four diffs under canonical #14 target four different objects (none is dd-07, #14's actual subject)** — bundled by genre ("stress-test an internal formalism against external data"), violating the artifact's own criterion (a). A recurring structural cause: orphaned families with no canonical of their own (`channel-substitution`, `collective-continuity`, `safety-selection-neutrality`, `de-novo-coordination`) were absorbed into the nearest topical canonical rather than flagged as new roots.

**120-word canonicals dropped load-bearing content.** #11 (`content-blind…`) omits condition (ii), cross-lineage portability with *different* tokens — changing what the "decisive test" requires. #3 drops its two validity caveats (B must be measured on non-source carriers or it's a constant; needs longitudinal multi-turnover) without which the metric doesn't discriminate at all.

**Second-order content dropped wholesale.** Every file's Evidence status (what's run vs. missing, with numbers), Novelty note (external anchors, near-duplicates, already-retreated candidates like `stigmergic-trace-causality.md`), and "New sparks" (often independently substantive — GURT/terminator-seed governance analogy, hyperedge-fuzzing attack surface, verifier crime-wave signature) are gone.

## 2. Distortions introduced

**Inflated novelty.** Files that self-temper are presented as unqualified fresh territory: `succession-complexity-anti-extraction` (#23) drops "should not be oversold as novel — literature already moved past ad hoc framing"; `drift-vs-selection` (#10) is actually a *correction* of an overclaiming seed (machinery exists in 4 repo files) but reads as fresh gap-discovery; `salience-governance`'s taxonomy "already exists verbatim" in a prior brief; `co-evolving-evaluator`'s bare claim is already published (RQGM, arXiv:2606.26294), making it a correction the diff hides.

**Suppressed contradiction / inflated confidence.** `selection-signal-collapse`'s regime-decomposition-P3 was marked **CONTRADICTED 2026-07-01** (dorm-06: emergence is seed-driven, not selection-driven); canonicals #9 and its diffs (`exploit-niche`, `verifier's-dilemma`) rest on it, yet the artifact surfaces this *nowhere*, presenting them as motivated theory. Opposite-signed counter-theses (silly-rules, founder-effect/carrier-canonization, P5 dual-mechanism, `cold-succession`'s competing hypothesis) are systematically dropped, inflating directional confidence.

**Inflated independence/count.** Canonical #8 opens by disclaiming standalone status ("a narrower instance of an already-existing dossier" — the same one #9 builds on), so 23 is inflated. `self-immunity-P1` (a single 2026-07-01 run) is primary evidence across ≥4 files; evidence independence is far lower than the canonical count implies.

## 3. Uniquely preserved

The canonical+diff form keeps the *relational delta* — what each satellite spark changes relative to an anchor (different external anchor, added control arm, corrected claim). A thematic cluster or flat linked-object list would flatten these into mere co-membership; a narrative essay would bury them; consequence-class bucketing would merge distinct mechanisms. Where parentage is correct (`rediscovery-cost`, `sub-threshold-propagation`, `singular-learning-theory`, `task-driven-compression`, `self-other-bias`, `prospective-vs-retrospective`), the one-line delta is genuinely informative and compact. It also uniquely exposes redundancy structure — which sparks are minor variations of a shared move — that other forms hide.
