# Compression-Loss Experiment (2026-07-02)

A controlled experiment on the repo's own idea layer: compress the 69-spark
`Paper/incubator/discovered-sparks/` corpus (~88k words) five independent ways,
audit each for actual structural loss against the originals, and read what the
losses reveal about compression as a repo operation.

- **Durable theory record:**
  [`Paper/theory/references/compression-loss-experiment-2026-07-02.md`](../../Paper/theory/references/compression-loss-experiment-2026-07-02.md)
  (the citable reference; results 1–3 + consequences).
- **`SYNTHESIS.md`** — cross-scheme synthesis (invariant loss, complementary
  preservation, self-audit blind spot, implications).
- **`artifacts/`** — the five compression products, verbatim (A thematic
  clusters, B flat objects+links, C narrative essay, D canonical+diffs, E
  consequence classes), each ≤2,500 words.
- **`audits/`** — the five independent loss audits, verbatim, one per scheme.

## Why this lives here (not in `Paper/`)

This is a development/method experiment on the control plane itself, not a
science result about Quine. `Paper/theory/references/` holds the citable
compressed record; this directory holds the raw evidence (artifacts + audits)
behind it — kept per the experiment's own finding that the raw layer must not
be overwritten by any single compressed projection.
