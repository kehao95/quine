# 6M Corpus as Ecology Seed

**Status:** matured (surfaced during 2026-07 backlog-maturation pass; not yet promoted)

## Matured claim

Re-hydrating the already-collected 61-row 6M.01-6M.10 successor-morphology
corpus as a frozen standing-variation roster inside a drq-03-style demand
arena is a legitimate, cheap common-garden selection assay for
body-ecology-coupling's open gap — it can test whether morphology classes
that differ only because of their original induction condition also differ
in survival or request-share under one shared network-utility-selection
regime — but it closes at most 2 of the 3 conditions body-ecology-coupling.md
requires (cross-sectional body variation plus network-utility selection),
not condition 3 (heritable inheritance of winners across generations), so it
can stage the gap but not close it. Its near-zero-marginal-cost framing is
true only for the diversity-generation step (already paid for by 6M); it
hides two real costs: per-body-class re-hydration or adapter engineering to
make artifacts built for 6M's own single-shot carrier protocol answer
drq-03's different demand protocol, and the ongoing live-inference cost of
any re-instantiated body that is itself an LLM agent loop.

## Theory spine

self-description-resource x carrier -> successor-morphology (6M's
M=<B,S,C,T,H,A,R,V>) -> retained/DVC-archived run = frozen cross-sectional
phenotype sample, not a live process -> re-hydration of a frozen body into a
live addressable service (per-body-class carrier-adapter cost, not free) ->
common-garden assay: many already-different frozen phenotypes placed in one
shared selective environment -> network-utility-selection (drq-03-style
demand arena; existence = costly exec-gated addressing) ->
body-ecology-coupling gap: satisfies conditions 1 (cross-sectional) plus 2,
not condition 3 (heritable inheritance across generations) ->
symmetry-trap-phase: candidate signature test — does injecting pre-existing
morphological diversity produce character displacement instead of the
drq-03 symmetry trap -> selection-signal-collapse / unfakeable-selection:
demand must remain exec-gated or costly or the arena collapses back to the
same narrative-satisfiable trap

## Evidence status

No experiment wiring 6M artifacts into drq-03 or any arena exists; both
halves (the 61-row 6M.01-6M.10 corpus and the active drq-03 host-lineage
arena) are independently mature but never combined, and
body-ecology-coupling.md's evidence table literally lists this combination
as the empty future yes/yes/yes row, though this seed done honestly would
only fill it yes/yes/no. A decisive experiment needs: select 3-5 maximally
differentiated 6M body classes; build and cost-log a thin per-class carrier
adapter so drq-03's match and judge protocol can address each body through
its own native carrier rather than forcing one shared protocol; run a small
replicated tournament with a costly exec-gated demand generator plus a
same-body-class-vs-itself control; test whether body class predicts
request-share or survival across replicates, falsified if all bodies
converge to the same minimal-liveness strategy regardless of body; and
report total adapter-engineering plus inference cost against a
fresh-induction baseline, since the near-zero-marginal-cost premise, not the
ecological hypothesis, is this seed's weakest load-bearing claim.

(successor-morphology, network-utility-selection, body-ecology-coupling,
symmetry-trap-phase) into a specific operational move (reuse instead of
regenerate). It also functions as the individual-to-ecological projection of

## New sparks this seed surfaced

- **ecological-common-garden-vs-developmental-clone-split:** The repo's
  existing common-garden usage means single-genotype clone-split across
  demand levels to prove within-lineage facultative plasticity; the
  between-body question this seed needs, many already-different 6M
  phenotypes surviving together in one shared network-utility arena to test
  whether standing variation is selectively relevant, is the textbook
  ecological common-garden design and is currently unnamed and unowned in
  the repo; both rungs should be explicitly staged so future work doesn't
  conflate them.
- **pfsp-matchmaking-as-symmetry-trap-exit:** AlphaStar-style Prioritized
  Fictitious Self-Play matchmaking, biasing rematches toward opponents with
  low win-rate, against a frozen pool of already-diverse 6M bodies is a
  structural, no-heritability-required exit from the drq-03 symmetry trap,
  complementing symmetry-trap-phase.md's three named exits with a fourth
  that is cheap to test with the existing corpus alone.
