# Control-Plane Causal Path Contract

[DEVELOPMENT](../../DEVELOPMENT.md) routes changes to working instructions,
procedures, and indexes here.

When a document is intended to guide action, consider who reads it, what it
helps them do, and how stale instructions would be noticed. Update actual
consumers when paths, schemas, or operational facts change. Exploratory accounts
can remain useful before their future consequences are known.

Use an existing source or generated projection for repeated operational facts.
Add a rule or validator when it serves a concrete need. Checks can verify files,
links, schemas, generated content, and behavior; keyword presence cannot verify
that an author understood a question or that two accounts mean the same thing.
See the [proxy-enforcement failure](../../evolution/failures/proxy-enforcement-collapse.md).
