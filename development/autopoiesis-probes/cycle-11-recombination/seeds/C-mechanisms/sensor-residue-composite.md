# sensor-residue-composite

**What:** The selected unit may be residue plus executable sensor, not the
residue alone.

Plant identical stale facts in two habitats. In one, the fact is passive residue.
In the other, an executable validator, heartbeat, or watcher reports it as an
actionable condition. The mechanism predicts that only the sensor-coupled residue
crosses from survival into uptake, legitimacy, and reproduction.

Trigger != validation. A validator firing is only a trigger. Validation requires
showing that the same residue without the executable sensor does not produce the
same future action, and that sensor activation alone without relevant residue is
insufficient.
