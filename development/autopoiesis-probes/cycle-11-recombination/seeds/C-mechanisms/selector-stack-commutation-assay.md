# selector-stack-commutation-assay

**What:** Carrier selection may be non-commuting: the same selectors can produce
different winners when applied in different orders.

Construct matched runs with the same founding history, physical bottleneck,
addressability lease, stimulation rule, governance membrane, and reproduction
path, but permute which selector acts first. Pre-register the measured contest
before the run: survival, uptake, summons, legitimacy, arbitration, or
reproduction.

Trigger != validation. A run where one surface first stimulates action only
shows a candidate trigger. Validation requires order-specific predictions that
survive counterbalanced prompt salience and constant residue content.
