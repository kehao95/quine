# history-installed-stimulation-switch

**What:** A founding trigger may install the stimulation rule that later decides
which residue is carrier-shaped.

Create two lineages with different first successful triggers, such as direct
control-handle attention versus public status-file attention. After the lineages
stabilize, expose both to the same final bottleneck and the same available
residue. Predict whether the earlier trigger changes which residue the fresh
agent treats as salient and legitimate.

Trigger != validation. Finding that a lineage notices its founder-associated
surface is only a candidate signal. Validation requires a founder-switch control
where final bottleneck, residue, and prompt naming are held constant.
