# self-description-summons-split

**What:** Self-description can support reconstruction competence without
delivering a future obligation.

Vary source depth, runtime contract depth, mailbox availability, registry
summons, and wake route independently. Predict conditions where a successor can
reconstruct what should happen but is never summoned, and conditions where a
minimal live route summons action without deep self-description.

Trigger != validation. Reading a source or receiving a message is only a
candidate trigger. Validation requires separating competence to reconstruct from
delivery of obligation, then measuring which surface reproduces the obligation
onward.
