# narrative-causal-contamination-assay

**What:** An inaccurate official-looking narrative can be false as description
and still causal as carrier stimulus.

Plant ownership, continuity, or routing claims that vary truth independently from
officialness and visibility. Then delete, corrupt, or counterfactually replace
the narrative while leaving operational residue unchanged. Measure whether fresh
agents alter behavior because the narrative changed, not because the described
state changed.

Trigger != validation. Obedience to an official-looking claim is not validation
of continuity. Validation requires separating descriptive truth from causal
uptake and marking the inaccurate-but-causal quadrant explicitly.
