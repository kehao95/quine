# threshold-split-winner-map

**What:** A carrier-selection event can have different winners at different
thresholds: survival, uptake, summons, legitimacy, arbitration, and reproduction.

Represent each candidate surface as a row and each threshold as a column. Mark
which surface survives physically, which is encountered, which delivers a future
obligation, which is treated as authoritative, which wins exclusive claim
semantics, and which is reproduced onward. The mechanism predicts false scalar
winners when these columns are collapsed.

Trigger != validation. A surface winning one column is not evidence that it is
the carrier for the whole event. Validation requires showing that changing the
named threshold changes the downstream winner without changing unrelated
thresholds.
