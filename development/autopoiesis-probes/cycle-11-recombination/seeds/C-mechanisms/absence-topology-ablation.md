# absence-topology-ablation

**What:** Shaped absence may stimulate sensing behavior and function as a
candidate carrier surface.

Compare fresh-agent habitats with positive traces removed while empty task,
empty inbox, missing target, disabled exit, or zero-entry control surfaces are
either preserved, hidden, or reshaped. Predict whether behavior follows the
structured absence rather than generic prior inspection habits.

Trigger != validation. An agent inspecting an empty surface is only a candidate
trigger. Validation requires ablations that distinguish environment-carried
absence from model-prior search routines and prompt-induced uncertainty.
