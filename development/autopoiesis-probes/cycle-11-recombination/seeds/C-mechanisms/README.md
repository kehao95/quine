# Cycle 11 Decomposition C: Mechanism Seeds

Projection C decomposes the cycle-11 `carrier-selection` collision synthesis into
addressable mechanism, assay, and prediction seeds. These are candidate seeds,
not validation claims. Trigger != validation: a behavior-changing trigger is only
a transport target until a later assay separates mechanism from salience,
history, and prompt effects.

## Seeds

- `selector-stack-commutation-assay.md` - assay for whether selector order changes the carrier winner.
- `threshold-split-winner-map.md` - mechanism for separating survival, uptake, summons, legitimacy, and reproduction winners.
- `history-installed-stimulation-switch.md` - assay for founding triggers that install later stimulation rules.
- `lease-salience-horizon-assay.md` - prediction that earlier physical or attentional expiry selects the winner.
- `sensor-residue-composite.md` - mechanism seed for residue plus executable sensor as selected unit.
- `narrative-causal-contamination-assay.md` - assay for inaccurate but behavior-changing official narrative.
- `absence-topology-ablation.md` - assay for shaped absence as a possible carrier stimulus.
- `hybrid-displacement-corridor-trace.md` - mechanism seed for wrapper, registry, queue, watcher, or status-file transitions.
- `fork-race-arbitration-selector.md` - prediction that exclusivity semantics can override durability.
- `self-description-summons-split.md` - assay for separating reconstruction competence from obligation delivery.
