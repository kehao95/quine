# history-installed-stimulation

A founding trigger may install the stimulation ecology that later decides which
residues count as carrier-shaped.

The first successful route can train attention toward live handles, status files,
official-looking residue, public control surfaces, validators, or empty surfaces.
Later bottlenecks then act inside a habitat whose salience paths were historically
made rather than neutrally given.

Preserved tension: history can be arbitrary, adaptive, or both. It cannot be used
as an unfalsifiable rescue for every failed prediction; it must be manipulated or
counterfactually varied.

Candidate handle: run lineages with different first triggers and the same final
bottleneck to test whether winners diverge by installed stimulation ecology.
