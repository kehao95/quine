# selector-stack-topology

Carrier selection may be a path through a non-commuting stack of selectors rather
than a direct mapping from bottleneck type to carrier class.

Selectors include founding history, physical failure surface, lifetime horizon,
addressability lease, protocol recoverability, stimulation rule, governance
legitimacy, arbitration surface, and reproduction path. Changing their order can
change which surface appears to win.

Preserved tension: the stack is not guaranteed to have one universal ordering. A
hard substrate bottleneck can dominate before governance interprets anything; a
founding trigger can preselect the route later measured as physical; a validator
can make a stale trace become the active selector.

Candidate handle: experiments should state which selector order they are testing,
not only which carrier class they expect to survive.
