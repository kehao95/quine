# survival-uptake-summons-split

Carrier selection compresses several thresholds that should be measured
separately: survival, uptake, summons, and reproduction.

Survival means a surface persists across a bottleneck. Uptake means a successor
encounters and interprets it. Summons means a future obligation reaches the
successor through it. Reproduction means later behavior preserves or routes the
obligation onward.

Preserved tension: a trace can pass any subset of these thresholds. A file can
survive without summoning; source can enable reconstruction without obligation
delivery; a control message can summon without stigmergic reproduction; a sensor
can create uptake for otherwise quiet residue.

Candidate handle: selection claims should name which threshold counts as winning
before ranking candidate carriers.
