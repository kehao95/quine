# Selector Stack Noncommutativity

## Tension

`bottleneck type -> carrier class winner` is too flat. The synthesis points to a
stack of selectors: founding history, physical failure surface, lifetime horizon,
addressability, protocol recovery, stimulation rule, legitimacy, arbitration, and
reproduction path. These selectors may not commute.

## Failure Mode

If the experiment records only a final carrier class, it may mistake a projection
of the selector path for the selection rule itself. Two regimes can share the same
final bottleneck but differ because earlier selectors installed different
stimulation ecologies or arbitration surfaces.

## Open Question

Which selector order is active in a given carrier-selection event, and what
observable would distinguish order effects from simple class strength?
