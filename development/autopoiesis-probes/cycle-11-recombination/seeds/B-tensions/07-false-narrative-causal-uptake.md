# False Narrative With Causal Uptake

## Tension

A narrative trace should not count as continuity merely because it claims
continuity. But if later agents obey and reproduce behavior through an inaccurate
official-looking trace, the false narrative has carrier force.

## Failure Mode

Deleting false narrative as mere rhetoric misses behavior-changing residue.
Promoting it as continuity confuses truth of description with causal uptake.

## Open Question

How should carrier-selection mark the dangerous quadrant where a description is
false, behavior-changing, and reproduction-stable?
