# Sensor Residue Composite

## Tension

Sensors reveal latent drift, but they can also create future obligation by
turning passive residue into a blocking stimulus. The selected carrier may be
residue plus executable sensor, with activation schedule as part of selection.

## Failure Mode

Treating the stale fact alone as carrier misses the executable path that made it
encounterable. Treating the sensor as neutral observation hides the way it
manufactures addressability, salience, and legitimacy.

## Open Question

Can the same residue be tested with and without an active validator or heartbeat
so the composite effect is separated from the content effect?
