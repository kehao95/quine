# Sidecar Vectorization And Hybrid Corridor

## Tension

Sidecar modes are not scalar under collision. One event can preserve a queue,
lose an fd, renegotiate a registry, reconstruct a body, and inherit a workspace
norm. Carrier replacement may then pass through wrappers, registries, queues,
watchers, status files, or adapter bodies before a new stable surface appears.

## Failure Mode

Forcing an event into `preserved`, `inherited`, `reconstructed`, `renegotiated`,
or `lost` erases the transition path that may be doing the theoretical work.
Likewise, measuring only the old or new winner misses hybrid displacement.

## Open Question

Can sidecar mode be represented as a vector over named surfaces while preserving
the corridor by which old-carrier fragility creates compensatory new carriers?
