# Cycle 11 Target Selection

## Structural Pull Declared

This round is pulled toward turning an open gap into an object too early, because
the theory graph rewards addressable objects and prior recombination cycles
ended with promoted dimensions. Discount: treat promotion as conditional on a
robust residue after collision, not as the reason for selecting the target.

## Selected Target

**Target:** `carrier-selection`

**Frame:** a trigger-conditioned selection rule for which carrier class wins
under which bottleneck, and what makes a trace cross from weak residue into a
load-bearing carrier.

**Canonical gap:** `Paper/theory/gaps/carrier-selection.md`

## Why This Target

- It is `scope: theoretical`, `OPEN (unowned)`, and therefore autonomous-safe to
  grow without resolving a paradigm object.
- It connects multiple existing objects: `trigger-structure`,
  `successor-morphology`, `stigmergy-as-carrier`, `self-description-resource`,
  `trace-inheritance`, `affordance-null-ecology`, `continuity-substrate`, and the
  paradigm object `carrier`.
- It has an explicit transport shape: a real selection rule should predict
  carrier-class winners under bottlenecks not already used to fit the rule
  (idle-GC reclamation, fork-race under resource pressure, substrate shift).
- It has not already been the cycle-9 or cycle-10 target, unlike
  `commutator-friction` and `divergence-substrate`.
- It promises new dimensions because the current gap framing is internally
  tense: competitive selection, historical lock-in, exaptation, stigmergic
  threshold crossing, and self-description/resource availability may all select
  different winners.

## Neighboring Seeds Already Present

- `trigger-structure` carries a seed that reframes selection as historical
  founding inertia: the first trigger can lock a lineage into a carrier-class
  niche.
- `successor-morphology` carries a seed that reframes selection as exaptation:
  morphology selected under one pressure can be co-opted under another pressure.
- `stigmergy-as-carrier` carries the weak-vs-causal threshold: a trace must alter
  later behavior through a stimulation rule before it counts as a carrier.
- `self-description-resource` has no live seeds yet but is a critical missing
  axis: reconstructive material is not itself the carrier, yet it changes which
  successor morphology can be selected.

## Lens Plan

1. **Evolutionary / historical lens:** selection as founding event, inertia,
   exaptation, neutral entrenchment, and path-dependent carrier-class niches.
2. **Substrate / operations lens:** selection as survival across concrete
   bottleneck physics: exec, fd/socket persistence, idle GC, queues, filesystem
   residue, source availability, and addressability horizons.
3. **Stigmergic / governance lens:** selection as weak-to-causal threshold
   crossing in an agent habitat: salience, stimulation rules, control surfaces,
   affordance null ecologies, and narrative-vs-functional discrimination.

## Non-Targets

- Do not resolve the paradigm-scope `carrier` object.
- Do not select `commutator-friction` or `divergence-substrate`.
- Do not collapse the lenses into a consensus rule; preserve the tension between
  competitive fit, historical lock-in, exaptation, and causal trace uptake.

## Desired Output Shape

The round should produce a collision surface that can later become either:

- a candidate relation on `carrier-selection` / `carrier`, if it yields a stable
  selection grammar; or
- one or more `SEED` concepts about selection regimes, if the collision shows the
  gap is actually multiple coupled mechanisms.
