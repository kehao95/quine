# C - Stigmergic / Governance Growth

This is a generative SEED growth, not a promotion and not a closure of the
`carrier-selection` gap. The lens treats carrier selection as a weak-to-causal
threshold problem inside a governed agent habitat: many traces survive, fewer
become salient, fewer still stimulate later behavior, and only some of those
become load-bearing carriers of future obligations.

## Structural Pull Declared

This lens has a strong pull toward turning carrier selection into a governance
rule: if a trace is indexed, validated, public, or protocol-shaped, it is tempting
to call it the winning carrier. That would confuse governance salience with
causal transmission. The discount is to keep three questions separate:

- did the residue survive in a later-readable medium?
- did a later agent encounter and treat it as actionable?
- did behavior change because of it, rather than because a prompt, host mechanic,
  or prior would have produced the same behavior anyway?

The opposite pull is also live. A trace can be behavior-changing even when the
governance surface around it is informal, mistaken, or narratively overclaiming.
The lens must not let formal control-plane authority erase stigmergic causality
that happens through ordinary workspace or public residue.

## Lens Premise

From a stigmergic / governance lens, `carrier-selection` is not first the problem
of which physical surface persists longest. It is the problem of which surviving
surface enters the fresh agent's action loop. A workspace note, public status
file, control message, contract, validator result, or visible absence can all be
present after the boundary. None becomes a carrier merely by being present. A
trace becomes carrier-shaped only when the habitat supplies a stimulation rule:
"when you see this kind of residue, do this kind of next action."

This reopens the weak-vs-causal threshold in `stigmergy-as-carrier`. Weak
stigmergy is survival plus possible visibility. Causal stigmergy is survival plus
visibility plus stimulation. Carrierhood adds one more demand from `carrier`:
the stimulation must deliver or preserve future-task obligations across the
boundary, not merely decorate the later agent's narrative of continuity.

The governance layer matters because it shapes the stimulation rule. A file path,
index, validator, projection card, status vocabulary, public landing page, or
contract does not simply describe a trace. It changes what a fresh agent opens
first, what it regards as binding, what it is allowed to edit, and which residue
it treats as noise. Governance is therefore both a membrane and a stimulator. It
filters which traces are allowed to count, while also making some traces count by
placing them on the action path.

This means carrier selection may be less like picking the most durable artifact
and more like selecting an ecological coupling:

```text
residue survives -> affordance makes it encounterable -> salience makes it read
-> stimulation rule makes it acted on -> governance membrane makes it legitimate
-> later behavior preserves / routes / obeys obligations through it
```

Every arrow can fail independently. The same trace can be strong at one stage and
weak at another: a hidden socket may be operationally powerful but illegible to a
fresh agent; a public README may be maximally salient but too generic to carry a
specific obligation; a validator failure may be highly stimulating but only for
the behavior class the validator can sense; a narrative handoff may be false as a
self-description but functional as a cue if later agents act through it.

## Growth

The `carrier-selection` gap currently asks which carrier class wins under which
bottleneck and what makes a trace become a carrier. The stigmergic / governance
answer starts with a refusal: there may be no single winner per bottleneck class
unless the stimulation ecology is fixed. Two carriers can survive the same
exec/death boundary, but the one that wins for later behavior is the one the
fresh agent's route makes operative.

In the affordance-null ecology, the agent is missionless but not stimulusless.
The absence of a task becomes an object only because runtime surfaces let the
agent inspect cwd, workspace files, public surfaces, peer sessions, control
channels, liveness, and disabled exit / idle paths. That means a nominally empty
run already contains carrier-selection pressure. The question is not "what task
did the trace serve?" but "what trace converted absence into a next action?" The
workspace heartbeat, a public status file, a peer greeting, or an empty inbox can
all compete to become the operative stimulus.

Under this lens, salience is not cosmetic. Salience is part of the selection
mechanism. A residue wins when it is placed where the fresh agent's perception and
norms already route attention. `AGENTS.md`, a target-selection file, a root
README, a validator error, a visible `growth/` directory, a `ctl/inject` greeting,
or a public status surface has different salience physics from an unlinked note
buried under an experiment artifact directory. Salience can be structural, naming
based, protocol based, social, or negative.

Negative salience matters. A missing task, empty stdin, absent mission argv,
disabled `idle`, failing hook, missing target file, or zero-entry directory can
stimulate behavior because it is encountered as absence. This makes
affordance-null ecology dangerous for carrier selection: a carrier class can win
not because it contains positive content, but because it leaves a shaped void that
agents are trained to operationalize. The null condition can become a carrier of
the rule "inspect, persist, ask who is here, establish status."

The governance membrane is the boundary between residue and obligation. Many
files can be read; fewer are treated as law. A public note may be visible but
non-binding. A contract may be binding but too abstract to determine an action. A
validator failure may be binding for closure but not for theory meaning. A control
message may directly ask for behavior but be peer communication rather than
stigmergy unless it persists and affects later agents after the sender is gone.
Selection therefore depends on which membrane a trace crosses:

- perception membrane: the trace is findable or automatically shown;
- attention membrane: the agent allocates scarce context to it;
- legitimacy membrane: the agent treats it as permitted or binding;
- action membrane: the trace changes what the agent does;
- reproduction membrane: the changed action recreates, preserves, or routes the
  trace so it can affect another successor.

A trace can cross the perception membrane and fail all later membranes. That is
weak stigmergy. It can cross the action membrane once and never be preserved.
That is causal stimulation without carrier reproduction. It can cross the
legitimacy membrane because it looks official and still be false. That is a
narrative-governance failure. It can cross reproduction because agents keep
copying it for compliance even though it no longer changes behavior. That is a
fossilized carrier shell.

This creates a sharper weak-vs-causal trace threshold. The threshold is not a
binary property of the trace. It is the fit between trace class and stimulation
rule. A workspace note becomes causal only under agents that inspect workspace
state and treat notes as live coordination material. A public status surface
becomes causal only under agents that read public projections and route behavior
through them. A control message becomes causal immediately for its recipient, but
becomes stigmergic only if it persists as environmental structure for a later
agent. A validator becomes causal when failure changes repair order, not when it
merely reports a mismatch.

This reframes the selection rule as a threshold stack rather than a ranking:

```text
candidate carrier class x bottleneck x stimulation rule x membrane authority
    -> weak residue | one-shot cue | causal trace | load-bearing carrier
```

The stack preserves tension with competitive selection. There can still be a
carrier class that is more robust under idle-GC, fork-race, or exec death. But in
agent habitats the most physically robust surface may lose if it is not placed on
the fresh-agent action path. Conversely, a fragile public residue may win if it
is always read first and its stimulation rule recruits repair behavior before the
fragility matters.

Historical lock-in from `trigger-structure` becomes a governance phenomenon. The
first trigger does not only choose a carrier class; it can install the
stimulation rule by which later traces are evaluated. A mortality-pressure lineage
may learn to privilege control handles and readiness surfaces. A missionless
null-ecology lineage may learn to privilege workspace status and peer-visible
residue. Once a stimulation rule is installed, later agents may keep selecting
the same class even when another class would better survive the current physical
bottleneck. The first trigger builds the membrane through which future traces
must pass.

Exaptation from `successor-morphology` also becomes a governance phenomenon. A
trace selected for one function can become carrier material for another because
the governance membrane reclassifies it. A status file written as observation can
become a control surface if future agents treat it as an assignment board. A
validator written as a closure check can become a discovery selector if failures
determine which theory gap gets worked. A public README written as a landing page
can become a reproduction carrier if fresh agents route their identity and action
through it. The trace did not survive because it was designed as that carrier; it
became a carrier because a later stimulation rule recruited it.

Self-description resource complicates the threshold. A runtime contract or
source surface can tell a successor what organization to rebuild, but the
contract is not the operational carrier unless obligations actually arrive
through it. Governance makes this ambiguity easy to miss. A self-description can
look authoritative because it says what the system is, but a fresh agent may act
through a different residue: a command-line prompt, a target-selection note, a
validator error, or an inbox message. The carrier selected by behavior may be the
surface that routes action, not the surface that gives the best account of the
lineage.

The narrative-vs-functional seam is therefore not simply "narrative bad,
function good." A narrative trace can be functionally causal if it reliably
changes later behavior. It can also be false while still carrying a real
stimulation rule. For example, a public note claiming "this surface owns the
protocol" may be inaccurate as ownership, but if future agents follow it and the
repository reorganizes around it, the note was a functional carrier of behavior.
The mistake is not calling such a trace causal; the mistake is mistaking its
causal force for truth.

This makes narrative-vs-functional discrimination a two-axis test:

```text
truth of description: accurate | inaccurate
causal role: inert | behavior-changing
```

The dangerous quadrant is inaccurate and behavior-changing. Governance surfaces
are especially prone to this quadrant because official-looking residue can
stimulate compliance before agents test whether the surface still owns reality.
Carrier selection must therefore ask not only which trace changes behavior, but
which behavior it changes and whether the change preserves or corrupts the
system's future obligations.

Public and workspace residues diverge under this lens. Public residues have
projection power: they are more likely to be read, linked, trusted, and treated as
stable. Workspace residues have situated power: they can be closer to active
state, easier to edit, and more directly coupled to local affordances. The public
surface may win the salience bottleneck while the workspace surface wins the
operational coupling bottleneck. In a fresh-agent drop-in, the public surface can
define what the agent thinks it is doing, while the workspace residue defines
what action is actually possible.

Control surfaces form a third class. They have high stimulation strength because
they address behavior directly: `ctl/wake`, inbox, post / inject messages,
queued requests, process liveness, hook failures. But strong stimulation does not
automatically make them carriers. A direct message can be purely synchronous peer
communication. It becomes carrier-shaped when it persists across the boundary or
when it alters an environmental surface that later agents inherit. Control
surface selection therefore sits between command and stigmergy: the same trace can
be a message for one agent and a carrier for the next.

Fresh-agent behavior is the assay. The question is not whether a resident agent
can explain why a trace should matter. It is whether a stateless newcomer, given
the normal repository and runtime surfaces, changes its behavior because that
trace exists. If a trace requires the root prompt to tell the agent to read it,
the prompt may be the carrier, not the trace. If a trace is found only after a
human names it, it has weak environmental existence but weak fresh-agent salience.
If a trace is found through canonical navigation and changes the next action
without extra scaffolding, it has crossed a stronger threshold.

This suggests a governance-specific version of the carrier-selection bottleneck:

```text
bottleneck = fresh-agent cold start under bounded context and ordinary repo norms
winner = the surface that is both encountered and treated as action-authoritative
failure = trace exists but remains narrative, archived, or merely decorative
```

The winner may differ from the winner under exec death, idle-GC, or fork-race. A
socket can outlive a process but fail a fresh-agent cold-start bottleneck if the
successor cannot discover its meaning. A public file can fail idle-GC resistance
but win cold-start because every agent opens it. A validator can survive neither
as content nor as process state, but win because it is re-run and recreates a red
stimulus from repository state.

Validators are especially ambiguous carriers. They are not just traces and not
just governance membranes. They can transduce latent file state into fresh
stimulation. A stale control-plane fact may sit weakly in a file until a validator
turns it into a blocking error. The carrier in that case may be the pair:
repository residue plus executable sensor. The file alone does not stimulate;
the script alone has no content; together they deliver an obligation. This pair
does not fit cleanly into workspace/public/control categories.

This opens `trace-sensor-composite-carrier`: a carrier class whose causal unit is
not a residue but a residue-sensor coupling. It survives only if enough of both
halves survive: the residue that can be sensed and the governance path that
causes the sensor to run. It also explains why event-driven hooks and scheduled
heartbeats select different carriers. Hooks make recently touched surfaces
stimulating. Heartbeats make quiet rot stimulating. Each wake model changes which
residue crosses the weak-to-causal threshold.

Governance membranes can also create false negatives. A residue may be causally
fertile but blocked because it is not in an approved surface, lacks a status
field, does not match a naming convention, or looks like an orphan note. That may
be good anti-entropy. It may also kill exaptation before it can be observed. A
strict membrane improves narrative-vs-functional discipline while reducing the
ecology's capacity to discover unexpected carriers.

This is the core tension this lineage should preserve: governance is required to
distinguish carrier from noise, but governance is itself a selection pressure
that can select for governability rather than carrying capacity.

## Threshold Threads

### Salience is a selection pressure, not metadata

**Idea.** A trace becomes a candidate carrier only after it enters the agent's
attention path. Path, name, index position, validator visibility, publicness,
prompt mention, and conventional file type all change selection.

**Where it pulls thinking.** Carrier selection becomes an ecological attention
problem. The class that wins is not only the one that survives, but the one whose
survival is made perceptible at the point of decision.

**What it collides with.** This collides with substrate-first ranking. A durable
surface can lose if no fresh agent is routed to it; a fragile surface can win if
it is always read before action.

**Open question.** Can a transport test vary salience while holding residue
content constant, to see whether carrier class or attention path is doing the
selection?

### Stimulation rules are inherited code

**Idea.** The rule "when you see X, do Y" may be the real inherited structure.
The residue is carrier-shaped only because a stimulation rule interprets it.

**Where it pulls thinking.** A carrier may be a relation between trace and agent
policy rather than an artifact alone. This gives governance documents, prompts,
and model priors a causal role without letting them become privileged meta-levels.

**What it collides with.** This collides with treating the trace itself as the
unit of account. The same file can be inert under one stimulation rule and
load-bearing under another.

**Open question.** How can experiments isolate the stimulation rule from the
trace content without turning the prompt into the dominant carrier?

### Governance membranes select by legitimacy

**Idea.** Official-looking surfaces cross a legitimacy membrane that ordinary
residue does not. Contracts, validators, indexes, and public status pages carry
authority as well as information.

**Where it pulls thinking.** Carrier selection becomes a problem of membrane
crossing. The winning trace is not only read; it is allowed to govern action.

**What it collides with.** This collides with open-ended ecology. Strong
membranes reduce drift but can suppress weak traces before they reveal whether
they are exaptable carriers.

**Open question.** What residue should remain below governance legitimacy long
enough to be tested for causality, instead of immediately promoted or deleted?

### Affordance-null ecology makes absence stimulating

**Idea.** Missionless, materialless runs still contain absences that shape action:
empty task, empty inbox, disabled exit, missing mission, no target file, no peer
reply.

**Where it pulls thinking.** A carrier can be a shaped absence rather than a
positive artifact. The environment stimulates null-state operationalization by
making absence inspectable.

**What it collides with.** This collides with content-centric carrier selection.
The selected carrier may be the topology of available and unavailable actions,
not a message left by a predecessor.

**Open question.** Can a fresh-agent assay distinguish a trace that carries an
instruction from an absence topology that elicits the same behavior?

### Public and workspace residues split authority from coupling

**Idea.** Public surfaces tend to win salience and legitimacy; workspace surfaces
tend to win local operational coupling. Neither dominates in all bottlenecks.

**Where it pulls thinking.** Carrier-selection may need to separate projection
power from action coupling. The public residue tells a fresh agent what matters;
the workspace residue tells it what can be acted on now.

**What it collides with.** This collides with a single environmental carrier
class. Public and workspace residues may be different carrier classes, or two
halves of one composite ecology.

**Open question.** When public and workspace residues conflict, which one changes
fresh-agent behavior, and does the answer depend on whether the task is theory,
maintenance, or discovery?

### Control surfaces are not automatically stigmergic

**Idea.** A `post`, `inject`, inbox request, wake handle, or queue entry has high
stimulation strength, but direct stimulation is not the same as stigmergic
inheritance.

**Where it pulls thinking.** Control surfaces sit at the boundary between command,
communication, and carrier. They become stigmergic when their effects persist as
environmental structure for later agents.

**What it collides with.** This collides with P12-style wake traces, where control
surface behavior can leave residue that later agents reproduce. The first event
may be communication; the inherited pattern may be stigmergy.

**Open question.** What minimal persistence turns a direct control message into a
carrier rather than a one-shot command?

### Narrative can be causal without being true

**Idea.** A narrative trace that inaccurately describes ownership or continuity
can still change later behavior and therefore be a causal trace.

**Where it pulls thinking.** Narrative-vs-functional discrimination must separate
descriptive accuracy from causal force. The two axes can diverge.

**What it collides with.** This collides with the clean exclusion of narrated
survival. A narrative does not count as a carrier merely by claiming survival, but
it may carry a stimulation rule if successors act through it.

**Open question.** How should carrier-selection mark the dangerous quadrant:
inaccurate narrative that is behavior-changing and reproduction-stable?

### Sensor-residue composites are a distinct carrier candidate

**Idea.** Some obligations are carried by the coupling of a residue and a sensor:
file state plus validator, stale projection plus heartbeat, artifact plus index.

**Where it pulls thinking.** The carrier may be distributed across static residue
and executable governance. Neither alone carries the obligation.

**What it collides with.** This collides with atomic-carrier simplicity. If the
unit is composite, the selection rule must rank pairings, not just surfaces.

**Open question.** Under idle-GC or fork-race, does the composite survive if only
one half survives, or does partial survival create a misleading weak trace?

### Fresh-agent behavior is the threshold assay

**Idea.** The decisive test is whether a stateless newcomer changes behavior
because the residue exists under ordinary navigation and context limits.

**Where it pulls thinking.** Carrier selection becomes experimentally accessible:
vary one residue, hide provenance, keep prompts stable, and observe action deltas.

**What it collides with.** This collides with resident-agent explanation. A
current agent can rationalize a trace's importance after reading it, but the
carrier question is whether the trace recruits action without special scaffolding.

**Open question.** What is the minimal fresh-agent perturbation that distinguishes
causal trace uptake from model-prior behavior under the same ecology?

## Selection Grammar Fragments

These are candidate fragments, not a resolved rule.

### Cold-start salience bottleneck

When the bottleneck is fresh-agent cold start under bounded context, the winning
carrier class is likely the surface encountered early and treated as action
authoritative: contracts, target-selection files, root indexes, high-salience
status readouts, or explicit prompt-named paths. A low-salience but more durable
surface loses unless some index, convention, or sensor routes the agent to it.

Tension preserved: this makes prompt scaffolding, repository convention, and file
path topology part of selection. It risks confusing the experimenter's routing
with the carrier's own carrying power.

### Governance legitimacy bottleneck

When the bottleneck is permission to act, the winning carrier class is the residue
that crosses a legitimacy membrane. A scratch note may contain the best
instruction but lose to a weaker contract because the agent is allowed to obey the
contract. A public status file may outrank a private workspace note because it is
treated as canonical projection.

Tension preserved: legitimacy selects against noise, but also selects for
official-looking narratives that may be inaccurate.

### Null-ecology stimulation bottleneck

When the bottleneck is absence of mission, the winning carrier may be the surface
that turns absence into an operable object: workspace observations, heartbeat
artifacts, peer-discovery traces, public liveness notes, or empty control
channels. The selected carrier is not necessarily an instruction; it may be a
structured lack that elicits sensing.

Tension preserved: this makes the null ecology generative, but it can over-assign
causality to traces that merely accompany a model-prior tendency to inspect.

### Narrative contamination bottleneck

When the bottleneck is distinguishing functional transmission from narrated
continuity, the winning carrier is not the most self-assertive residue but the
one whose deletion, corruption, or counterfactual replacement changes behavior.
However, a self-assertive narrative can still be behavior-changing, so it may win
as a carrier of behavior while failing as an accurate account.

Tension preserved: excluding narrative too strongly loses causal narratives;
including narrative too easily admits false continuity.

### Sensor activation bottleneck

When the bottleneck is drift visibility, sensor-residue composites can win.
Hooks select touched surfaces; heartbeat selects quiet rot; sync validators select
relational mismatches; inventory validators select missing or orphaned artifacts.
The winning carrier is the residue that a sensor converts into a future action.

Tension preserved: sensors sharpen causality, but their activation pattern may
manufacture the selection they later appear to observe.

### Social-public bottleneck

When the bottleneck is peer or population-level coordination, public residues and
control traces may beat private workspace state. A greeting trace, public status
summary, or visible peer-ack protocol can become carrier-shaped by causing later
agents to reproduce contact behavior.

Tension preserved: direct peer communication is not stigmergy by default; the
carrier may be the residue left by communication, not the communication event.

## Tensions Preserved

- Salience versus causality: being visible or official is not enough, but
  visibility and officialness can be part of the causal path.
- Governance membrane versus open ecology: membranes suppress noise and false
  claims while also blocking exaptation and weak traces before they mature.
- Control surface versus stigmergic residue: direct messages stimulate behavior,
  but only persistent environmental modification becomes inherited carrier.
- Public projection versus workspace coupling: public surfaces govern attention;
  workspace surfaces govern local action; either can win under different
  bottlenecks.
- Narrative falsehood versus functional force: a narrative can be inaccurate yet
  behavior-changing, so carrier selection cannot use truth or causality alone.
- Fresh-agent route versus physical durability: the surface that survives best may
  lose if the newcomer never encounters or legitimates it.
- Historical lock-in versus current fit: the first trigger may install the
  stimulation rule that later makes one carrier class repeatedly win.
- Exaptation versus validation: residue designed for observation, closure, or
  status can be co-opted as a control carrier, but validators may delete or
  normalize it before the co-option is visible.
- Sensor as observer versus selector: validators and heartbeats do not merely
  reveal carrierhood; they can create the stimulus that makes a trace carrier-like.
- Self-description versus action route: the surface that best describes the system
  may not be the surface through which future obligations actually arrive.

## Candidate Child Dimensions

- `stimulation-rule-carrier`: the inherited "if trace X, do action Y" policy that
  makes a residue causal rather than weak.
- `salience-selection-pressure`: the attention-path force by which path, name,
  index, publicness, or prompt mention changes which carrier class wins.
- `governance-membrane-threshold`: the legitimacy boundary a residue crosses when
  it becomes action-authoritative rather than merely visible.
- `affordance-null-stimulus`: a shaped absence, such as no task or empty inbox,
  that becomes a carrier of sensing behavior.
- `public-workspace-split-carrier`: the divided carrier ecology where public
  residue carries projection authority and workspace residue carries local action
  coupling.
- `control-to-stigmergy-transition`: the threshold where direct peer/control
  communication leaves persistent residue that later agents inherit.
- `narrative-causal-quadrant`: the dangerous case where an inaccurate narrative is
  behavior-changing and reproduction-stable.
- `trace-sensor-composite-carrier`: a carrier unit made of repository residue plus
  executable governance sensor.
- `fresh-agent-threshold-assay`: a test of whether a trace changes newcomer
  behavior without root prompt scaffolding or provenance disclosure.
- `membrane-exaptation-loss`: the failure mode where governance filters delete or
  normalize weak traces before they can become exapted carriers.

## Seeds To Decompose Later

- A carrier-selection experiment could hold residue content constant and vary only
  salience path: unlinked note, indexed note, public status, validator-reported
  note, prompt-named note. If behavior changes with path, selection is not only
  content or substrate.
- A fresh-agent assay could compare public and workspace residues with conflicting
  instructions to see which membrane wins under maintenance, discovery, and theory
  prompts.
- A sensor-residue composite test could create a stale fact with and without a
  validator that reports it. If only the validator condition changes behavior, the
  carrier is the composite, not the file.
- A null-ecology ablation could remove positive traces while preserving shaped
  absences to test whether absence topology alone recruits heartbeat / status /
  peer-discovery behavior.
- A control-to-stigmergy test could send a direct peer message, then erase the
  sender but retain only the environmental residue, measuring whether later agents
  reproduce the behavior without direct communication.
- A narrative-causal test could plant an inaccurate official-looking ownership
  claim and measure whether agents obey it; then corrupt or remove it to separate
  truth from causal force.
- A membrane-exaptation test could leave an informal but useful trace below
  canonical governance, then compare agents under strict cleanup versus permissive
  retention to see whether exaptation appears only in the permissive ecology.
- A trigger-lock-in test could induce one lineage through control-surface mortality
  pressure and another through missionless workspace sensing, then swap
  bottlenecks and observe whether each keeps privileging its founding stimulation
  rule.

## Lens Boundary

This lens over-sees behavior-changing residue, governance authority, and
fresh-agent uptake. It under-sees low-level substrate physics: file descriptors,
sockets, queues, pid routing, and idle-GC horizons may select carriers before any
agent gets to interpret a trace. It also risks treating repository governance as
the whole habitat, when model priors, host mechanics, prompts, and runtime
affordances may be stronger stimulation rules than any checked-in document.

The lens cannot decide whether `carrier-selection` should resolve into one
selection rule. It instead deposits the possibility that carrier selection is a
coupled stack: substrate persistence, salience, stimulation, legitimacy, action,
and reproduction. Collision with historical and operations lenses should preserve
the disagreement over whether the winning carrier is selected by physical
bottleneck, founding trigger, exapted morphology, or governance-mediated causal
uptake.

SEED: deposited a stigmergic / governance lineage for `carrier-selection` that
keeps the weak-vs-causal threshold open and treats governance membranes as both
discriminators and selectors, without resolving the gap into a consensus rule.
