# Cycle-8 Decomposition A — Concept Seeds (38 proposed)

**Decomposition lens:** genuinely new concepts deserving standalone seeds
**Source:** collision material (seed + A/B/C growths + synthesis + divergence-substrate)

`reproductive-code-topology` should NOT become the umbrella that absorbs the rest; it is one seed among peers.

1. **`evaluation-transition-split`** — MDL is evaluation geometry, not a complete discovery mechanism. Recombination changes the transition operators that generate candidates. Dimension: separates scoring from move generation.
2. **`search-ecology`** — The optimized object is a population of deposited lineages, not a single hypothesis. Dimension: population-level epistemic organization.
3. **`recombinational-neighborhood`** — A local optimum is only local relative to an operator set. Recombination adds hypergraph transitions. Dimension: landscape topology.
4. **`branching-potential`** — A structure's value includes future option value preserved. Good compression lowers MDL without reducing reachable futures. Dimension: evolvability as distinct objective term.
5. **`short-window-selection-blindness`** — Recombinant structures may initially look worse by MDL. Short eval windows falsely reject them. Dimension: time-horizon failure.
6. **`projection-common-refinement`** — Compression quotients distinctions away; recombination recovers them by intersecting projections. Dimension: info-theoretic meaning of higher-dim synthesis.
7. **`synergistic-parent-selection`** — Recombination wants complementary parents at medium distance, not maximum agreement. Dimension: parent-distance criterion.
8. **`addressable-genotype`** — Undeposited insight is not evolutionary material. A recombinable genotype is heritable, addressable partial structure. Dimension: genotype condition.
9. **`recombinability-not-openness`** — Open space ≠ recombinant space. Recombination requires bounded, labeled, addressable, heritable material. Dimension: permissive openness vs functional recombinability.
10. **`collision-not-consensus`** — Consensus preserves common part, discards conflict. Recombination preserves conflict to infer hidden dimension. Dimension: integration method.
11. **`recombinant-autopoiesis`** — A self-maintaining system may preserve itself by regulatedly ceasing to be itself at one level. Dimension: autopoiesis through boundary wound.
12. **`fusion-addressability`** — A recombinant child earns continuity only if it preserves parent obligation basins, not merely vocabulary. Dimension: identity criterion for fusion.
13. **`parent-recoverability`** — A valid child must make its parents recoverable as projections. Dimension: recombination validity criterion.
14. **`narrative-hybrid`** — A hybrid can sound like both parents while preserving neither's load-bearing function. Dimension: recombination's narrative failure mode.
15. **`regulated-membrane`** — Branching potential is controlled permeability, not maximal openness. Dimension: boundary design.
16. **`lifted-minimality`** — Smallest repair inside current code may be maladaptive if current code is the local minimum. Dimension: reinterpretation of "smallest repair."
17. **`recombinational-fitness`** — Fitness for self-maintaining system is not external scalar. Dimension: fitness without scalar collapse.
18. **`identity-liquidity`** — Autopoietic maturity is deciding which boundary level may dissolve. Dimension: upward movement of individuality.
19. **`reproductive-niche`** — Seeds/probes/sandboxed outputs are reproductive niches, not loose notes. Dimension: environmental condition for variation survival.
20. **`probe-recombination-engine`** — The autopoiesis probe method is already a recombination engine. Dimension: concrete repo practice as evolutionary machinery.
21. **`integrator-as-enzyme`** — The integrator is a catalytic node, not a privileged meta-judge. Dimension: role ontology of synthesis.
22. **`procedure-reification`** — Procedures cannot recombine while only live execution habits. Dimension: procedure-as-material condition.
23. **`commutator-friction`** — When A-then-B ≠ B-then-A, repo discovered a missing dimension. Dimension: order-sensitivity as discovery signal.
24. **`lineage-retention`** — Recombination depends on how long divergent attempts remain addressable. Dimension: retention quality.
25. **`conflict-radius`** — Cost of admitting one honest new instance = how many files/validators must change. Dimension: structural resistance metric.
26. **`selection-shadow`** — Audit/judge/refute stages can suppress novelty before recombination. Dimension: temporal failure of evaluation.
27. **`germline-main`** — Main-only makes main the visible germline; divergent evolution through deposited conceptual gametes. Dimension: VCS topology as reproductive architecture.
28. **`gamete-contamination`** — A divergent probe contaminates germline when it mutates shared substrate before collision. Dimension: experimental hygiene.
29. **`light-prompt-divergence`** — Light prompts expose structural pull; heavy prompts scaffold away divergence. Dimension: prompt-weight as variation control.
30. **`repair-shadow-recombination`** — Repair shadow = failed recombination: one surface fixed, adjacent projections not remerged. Dimension: maintenance failure as incomplete hybridization.
31. **`reproductive-code-topology`** — Discovery systems maintain topology of addressable partial codes, membranes, carriers, collision surfaces. Dimension: arrangement of reproductive surfaces. (One seed among peers, NOT the umbrella.)
32. **`projection-object-type`** — One latent concept may need multiple projection files; graph holds multi-reading identity. Dimension: structural solution to FS flattening.
33. **`intra-snapshot-branching`** — Git branches diverge whole states; theory needs node-level divergence within a snapshot. Dimension: granularity of divergence.
34. **`divergence-preserving-deposition`** — Make material addressable without collapsing multiple readings. Dimension: deposition without quotienting.
35. **`collision-record-carrier`** — Collision records carry parent conflict, not just summaries. Dimension: collision artifact as heritable material.
36. **`trigger-validation-split`** — Internal collision generates candidate dimension but doesn't validate it. Dimension: discovery trigger vs evidence validation.
37. **`child-structural-signature`** — Useful recombination leaves structural trace (new axis/interface/file type). Dimension: observable signature.
38. **`canonical-target-branched-path`** — Canonicalization is convergence target, not permission to erase divergent paths. Dimension: reconciliation between single canonical and divergent growth.
