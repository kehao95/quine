# Cycle-8 Collision Synthesis — Reproductive Code Topology

**Agent:** codex-5.5-high (collision operator, read-only)
**Inputs:** seed (`evolutionary-recombination.md`) + 3 divergent growths (A-geometry, B-autopoiesis, C-practice)
**Method:** tension-preserving collision (not consensus averaging)

## Central Finding

The A+B+C collision exposes a dimension best named **reproductive code topology**:
discovery is not only search over hypotheses or compression over codes, but the
management of **addressable partial codes that can open boundaries, recombine through
noncommuting collisions, and re-close as function-bearing descendants**.

A saw the transition-operator geometry. B saw the identity-boundary wound and reclosure.
C saw the concrete repository mechanics that make lineages heritable. None alone could
see the full object: **a self-maintaining discovery system must evolve not just better
theories, but better reproductive topology for theories.**

## 1. Revealed Dimension — the reproductive layer of epistemology

Computational epistemology already has `C`, `H`, `ψ`, `a`, `π`. The collision reveals
another missing layer: **the population-level reproductive organization that determines
what partial codes survive long enough to collide**.

Distinctions each projection collapsed (now recovered):
- **Evaluation vs generation:** MDL scores candidates; recombination changes the move set
- **Openness vs recombinability:** open ≠ recombinant; recombination requires addressable,
  bounded, labeled, heritable material
- **Novel synthesis vs narrative hybrid:** a child can sound like both parents while
  preserving neither's obligations
- **Local self-preservation vs higher-order self-preservation:** a seed may die so the
  theory graph survives
- **Conflict vs noise:** unresolved tension is useful only when carried in locatable form
- **Canonical destination vs branched path:** canonicalization is convergence target, not
  permission to erase divergent gradients before collision
- **Procedure as code vs procedure as reproductive niche:** `π` is searchable procedure AND
  the membrane deciding what variations survive to be searched over later

## 2. Productive Tensions (preserved, not resolved)

- **Compression vs branching potential:** "simplicity now" and "evolvability later" are
  different objective terms
- **Identity preservation vs identity liquidity:** recombination shifts the unit of identity
  upward (seed → object → graph → research program)
- **Formal novelty vs functional continuity:** recombination is not valid just because novel
- **Permeability vs noise:** controlled permeability, not maximal openness
- **Main-only coherence vs population search:** population moved into documents/probes/seeds
- **Consensus closure vs recombination:** integration must first preserve conflict
- **Internal collision vs external validation:** trigger ≠ validation — collision generates
  the candidate dimension; transport must later validate it
- **No privileged meta-level vs integrator role:** the integrator is another node, not above

## 3. Richest Emergent Concept — reproductive code topology

> Discovery-capable systems do not merely optimize theories. They maintain a semi-permeable
> reproductive topology of addressable partial codes. Recombination occurs when noncommuting
> partial codes are collided, forcing a child code that preserves parent recoverability and
> obligation coverage while opening a search neighborhood unavailable to either parent alone.

Demanded by joint structure: A contributes population-level transition operator; B
contributes identity criterion (child must re-close around viable higher-order self); C
contributes substrate condition (parent lineages must be deposited as addressable artifacts).

## 4. Unified-But-Non-Rigid Theory Sketch

**Definitions:** lineage (deposited partial code), carrier (durable survival surface),
recombination operator (many-to-one transition), branching potential (option value from not
prematurely quotienting), fusion addressability (child preserves parent obligation basins),
commutator-friction (noncommuting moves reveal missing dimension), reproductive topology
(membrane-and-carrier organization).

**Core Claims:**
- MDL is evaluation geometry; recombination is transition operator changing the reachable neighborhood
- Compression is quotienting; recombination is common refinement across projections
- Recombination requires addressability (undeposited insight is not genotype)
- Self-maintaining recombination requires controlled boundary opening
- Valid child must satisfy novelty + parent recoverability + obligation coverage + action affordance + branching potential
- Noncommuting repair sequences are empirical signs of hidden dimensions
- Autopoiesis-probe method is a procedural recombination engine

**Failure Modes:** consensus collapse, narrative hybrid, selection-shadow, addressability
debt, porosity overload, gamete contamination, asexual main.

**Validation criterion:** a recombination matures only when a child artifact shows parentage
+ a new relation neither parent produced alone, then later improves routing/prediction/repair/transport.

## 5. Synthesis-Level Predictions (only from collision)

1. Novelty without fusion will decay (narrative hybrids cited but not routed)
2. Functional dependency beats human novelty judgment
3. Order sensitivity should fall after valid recombination (if it persists, dimension not recovered)
4. Recombination yield jointly limited by complementarity AND addressability
5. Short-window evaluation rejects some successful recombinations (immediate MDL penalty)
6. Semi-permeable seed surfaces outperform rigid gates and open notes
7. Main-only stays evolvable only if conceptual gametes retained
8. Procedure recombination requires reification (addressable manifests, not live execution)
9. Parent recoverability predicts long-term synthesis utility
10. Too many parents reduces validity (narrative complexity > obligation coverage)

## 7. Meta — the hybridization method itself

**Validated at mechanism level:** light prompts preserved projection differences; context
isolation produced distinct lineages; retained outputs made them addressable; explicit
collision prevented consensus averaging; seed openness preserved branching potential;
integrator exposed a child dimension no parent held alone.

**Not yet validated at scientific level:** no downstream fresh-agent test; no functional
dependency test; no external transport test; same-model probes may share blind spots;
Human prompt framing shaped outcome; integrator can still become consensus machine.

**Deepest revelation:** hybridization requires a **reproductive niche**. Probes are gametic
artifacts: partial, bounded, addressable, intentionally non-final. The integrator is not a
judge above them but an enzyme producing a viable child code.

**Next maturity step is NOT more synthesis prose.** It is a functional test: create/update
a theory object so future agents can use it, then measure whether it reduces
commutator-friction, preserves parent obligations, and generates predictions single-lens
growth would not have produced.
