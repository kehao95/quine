# repair-shadow-recombination

Repair shadow is failed recombination: one surface is fixed while adjacent projections are not remerged. Maintenance can therefore fail by producing an incomplete hybridization rather than by failing to patch any single file.

- Dimension: maintenance failure as incomplete hybridization.
