# formal-novelty-functional-continuity

**Tension:** Child must introduce new axis vs must preserve parent function.

A recombined child has to be more than a renamed parent, but it also has to inherit enough function that its descent is meaningful. Novelty without continuity is mutation noise; continuity without novelty is duplication.

Neither pole wins because valid descent requires both recognizable function and a new axis of organization. The dimension is valid-child criteria.

## What it would take to resolve later
A validity test for child artifacts that separates functional inheritance from merely narrative resemblance.
