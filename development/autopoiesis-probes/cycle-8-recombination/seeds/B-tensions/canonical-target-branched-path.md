# canonical-target-branched-path

**Tension:** Single canonical location vs multiple valid fix-gradients.

Canonical location reduces drift and makes ownership clear. But early in a repair, several paths may be valid because the system has not yet revealed which container or gradient is right.

Neither pole wins because canonicalization is necessary for closure, while premature canonicalization can suppress informative branches. The dimension is canonicalization timing.

## What it would take to resolve later
A timing rule for when multiple fix-gradients should remain separate and when they should be absorbed into one canonical target.
