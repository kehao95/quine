# minimal-repair-dimension-escape

**Tension:** Smallest repair in current code vs recombination changes code space.

The smallest repair is usually the safest coherent move inside the current frame. Recombination may alter the frame itself, making the locally smallest repair a way of preserving the wrong code space.

Neither pole wins because bounded repair prevents churn, while dimension escape can be the real repair. The dimension is that repair cost depends on operator set.

## What it would take to resolve later
A repair calculus that evaluates cost relative to the available transformation operators, not only the current structure.
