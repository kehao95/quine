# navigation-staleness

**Tension:** Hand-maintained prioritization aids vs static queues drift.

Navigation surfaces help agents choose what to do next, but hand-maintained queues can become stale and pull future work toward yesterday's priorities. The guide can become a source of drift.

Neither pole wins because agents need orientation, while static orientation can mislead. The dimension is dynamic control-plane.

## What it would take to resolve later
A navigation model that keeps prioritization useful without turning stale queues into false current state.
