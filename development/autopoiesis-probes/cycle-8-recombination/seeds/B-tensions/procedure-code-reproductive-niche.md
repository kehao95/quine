# procedure-code-reproductive-niche

**Tension:** Procedure π as searchable algorithm vs procedure as membrane for variation survival.

Procedure can be treated as code to search, optimize, and revise. But procedure also forms the niche in which variation either survives long enough to recombine or is filtered out too early.

Neither pole wins because procedure is both object of search and reproductive environment. The dimension is procedural ecology.

## What it would take to resolve later
