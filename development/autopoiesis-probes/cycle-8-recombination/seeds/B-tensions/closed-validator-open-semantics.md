# closed-validator-open-semantics

**Tension:** Closed enums enforce coherence vs open-attested preserves growth.

Closed validators keep surfaces consistent and machine-checkable. Open-attested semantics allow new categories to appear before the system knows how to enumerate them.

Neither pole wins because enforcement needs closure, while discovery needs semantic growth. The dimension is validator maturity.

## What it would take to resolve later
A maturity model for when a semantic field should remain open-attested and when it should become a closed enum.
