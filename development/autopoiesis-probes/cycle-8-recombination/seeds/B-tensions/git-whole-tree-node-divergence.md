# git-whole-tree-node-divergence

**Tension:** Git branches preserve whole snapshots vs cognition needs node-level divergence.

Git is excellent at preserving whole-tree alternatives, but cognitive divergence often appears around a specific seed, claim, or node. Whole-tree branching may be too coarse for conceptual recombination.

Neither pole wins because repository state needs coherent snapshots, while theory growth may need localized variants. The dimension is granularity of divergence carriers.

## What it would take to resolve later
A divergence carrier that can represent node-level conceptual alternatives without sacrificing whole-repo coherence.
