# too-many-parents-limit-experiment

**What:** Hybrid validity falls after too many parents.

Run recombination tasks with two, three, four, and more parent artifacts, holding time and agent skill roughly constant. Score parent recoverability, child axis clarity, and downstream usability.

It prevents the collapse into "more parents is always better" if validity peaks then falls. It fails if additional parents keep improving outcomes or if parent count is less important than parent compatibility.
