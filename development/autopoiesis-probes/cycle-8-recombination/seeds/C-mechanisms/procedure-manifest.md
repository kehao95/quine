# procedure-manifest

**What:** Procedures are reified as addressable objects before recombination.

Build this as a lightweight manifest for each procedure: purpose, inputs, outputs, loop boundary, validation, and known failure modes. Recombining procedures then works over explicit procedure genotypes instead of remembered practice.

It proves that procedure-level evolution needs durable carriers just like theory objects. It fails if manifests become static documentation that does not affect procedural recombination.
