# recombination-hyperedge

**What:** A many-to-one theory relation records `recombined-from: [A,B,C]`, child axis, and parent obligations.

Build this as a graph primitive rather than prose. A child object should declare multiple parents, the axis that only appears through their combination, and the obligations inherited from each parent.

It tests whether recombination requires a relation type richer than pairwise sibling edges. It is weakened if ordinary links preserve the same parent recoverability and future actionability.
