# repair-shadow-search

**What:** After repair, search adjacent surfaces for stale projections.

Build this as a closure requirement for structural repairs. When one surface changes, inspect nearby indexes, validators, docs, and examples for old projections that still describe the pre-repair structure.

It proves useful if it catches drift that ordinary local validation misses. It fails if adjacent searches produce mostly noise or make small repairs too expensive to close.
