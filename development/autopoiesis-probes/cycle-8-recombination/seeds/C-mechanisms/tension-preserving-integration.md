# tension-preserving-integration

**What:** An integration protocol asks what each projection makes visible that others cannot.

Build this as an operator over artifacts: before merging, answer the visibility question for every parent and preserve the answers in the child. The protocol should treat unresolved tension as material rather than as a defect to smooth away.

It proves that synthesis can increase dimensionality instead of averaging parents. It fails when the resulting artifact reads cleanly but no longer exposes the non-overlap that made recombination valuable.
