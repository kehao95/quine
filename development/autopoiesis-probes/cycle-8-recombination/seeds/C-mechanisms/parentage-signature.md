# parentage-signature

**What:** A child shows two or more parents plus a relation neither generated alone.

Detect this at the artifact level by requiring visible parent pointers and a child relation, axis, or test that is not present in any single parent. The signature separates recombination from ordinary elaboration.

It proves useful if it predicts which children have genuine hybrid value. It fails if valuable synthesis often has invisible parentage or if the signature can be faked by superficial citations.
