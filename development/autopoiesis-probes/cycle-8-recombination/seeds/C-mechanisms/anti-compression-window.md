# anti-compression-window

**What:** Allow temporary messiness after recombination before applying MDL judgment.

Build this as an evaluation timing rule: new recombinations receive a protected interval for divergent obligations, rough edges, and unresolved tensions. Only after that interval does the system judge whether the child compresses better than its parents.

It proves that early mess can be necessary for later synthesis. It fails if delayed judgment only preserves clutter or if immediate compression produces equal or better long-term recombination yield.
