# multi-lens-yield-assay

**What:** Divergent growth plus collision beats a single agent with the same context budget.

Run parallel conditions: one uses multiple lens-specific agents whose outputs are collided and recombined; the other uses one agent with equivalent total context and time. Compare novelty, prediction density, parent recoverability, and downstream reuse.

It proves the recombination thesis if multi-lens collision produces higher-yield artifacts under equal budget. It is disproved if the single-agent condition matches or exceeds yield without retained divergent branches.
