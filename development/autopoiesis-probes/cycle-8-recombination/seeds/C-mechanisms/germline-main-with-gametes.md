# germline-main-with-gametes

**What:** Main is the germline, while probes and seeds function as gametes.

Build this as a development topology metaphor with operational consequences: canonical state lives on main, but divergent seeds are retained as recombinable genetic material before selection. Promotion is reproduction into the germline, not mere cleanup.

It proves useful if it clarifies why retained non-main artifacts matter without authorizing branch sprawl. It fails if the metaphor obscures ownership, validation, or the repository's actual version-control rules.
