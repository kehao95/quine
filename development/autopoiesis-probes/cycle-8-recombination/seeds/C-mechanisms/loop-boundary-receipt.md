# loop-boundary-receipt

**What:** Every workflow names its entry selector, allocation rule, closure artifact, and registration target.

Build this as a receipt attached to workflow procedures. The receipt states how work enters the loop, how attention or resources are allocated, what artifact proves closure, and where the result is registered.

It proves useful if workflow gaps become visible before agents improvise incompatible closure. It fails if receipts duplicate procedure text without improving loop handoff or validation.
