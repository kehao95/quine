# retained-seed-promotion-prediction

**What:** Retained SEEDs have a higher reuse rate than session-only ideas.

Test this by sampling ideas that were deposited as seed files and ideas that remained only in session text, then checking future links, edits, promotions, and experiment designs. Control for initial quality when possible.

It proves the value of retention if seed files are reused more often after context reset. It fails if session-only ideas are equally reused or if reuse is driven only by explicit prompt reminders.
