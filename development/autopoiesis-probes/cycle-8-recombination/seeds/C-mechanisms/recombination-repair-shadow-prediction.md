# recombination-repair-shadow-prediction

**What:** Collision-derived repairs create fewer later repair-shadows.

Test this by comparing repairs generated from explicit collision records with repairs generated from single-surface audits. Later, run repair-shadow searches and count stale projections or adjacent drift created by each repair type.

It proves collision-derived repair is deeper if it leaves fewer missed adjacent surfaces. It fails if collision-derived repairs are broader but no cleaner than ordinary repairs.
