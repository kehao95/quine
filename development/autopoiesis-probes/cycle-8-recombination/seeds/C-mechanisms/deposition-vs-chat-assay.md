# deposition-vs-chat-assay

**What:** Deposited branches recombine more than chat-only branches.

Run matched idea-generation sessions where one condition writes seed files and the other leaves ideas in transcript. Later fresh agents attempt synthesis using available repository state, then compare reuse rate and quality of the original branches.

It proves deposition matters if file-backed branches are recombined more often or more accurately. It fails if chat-only ideas are equally recoverable and productive.
