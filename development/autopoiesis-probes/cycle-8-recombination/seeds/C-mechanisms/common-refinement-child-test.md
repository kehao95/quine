# common-refinement-child-test

**What:** A child restores distinctions each parent collapsed.

Construct recombinations where each parent compresses away a different distinction, then test whether the child can represent both without reverting to either parent's collapse. Fresh agents should be able to use the restored distinctions in later reasoning.

It proves the deepest geometry claim if recombination functions as common refinement rather than compromise. It fails if children mainly average parents or add vocabulary without restoring lost distinctions.
