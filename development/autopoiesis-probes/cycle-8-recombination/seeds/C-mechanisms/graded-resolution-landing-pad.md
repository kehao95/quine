# graded-resolution-landing-pad

**What:** Deposit the lightest reversible artifact now, then deepen when friction recurs.

Build this as a timing policy for uncertain material. A seed lands with a compact ID and minimal obligations; repeated reuse, conflict, or friction triggers richer structure such as edges, evidence, or promotion gates.

It proves that the repository can preserve option value without overbuilding every idea. It fails if light deposits are too weak to recover or if delayed deepening repeatedly loses critical context.
