# procedure-reification-experiment

**What:** Procedure recombination needs manifests rather than live memory.

Run procedure-combination tasks with explicit manifests and without them. Ask agents to recombine workflows, then compare boundary clarity, validation, and ability to preserve obligations from each source procedure.

It proves procedure genotypes matter if manifests produce more stable procedural children. It fails if agents can recombine procedures equally well from live context alone.
