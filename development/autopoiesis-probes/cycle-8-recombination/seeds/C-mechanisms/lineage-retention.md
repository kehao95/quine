# lineage-retention

**What:** Measure how many divergent attempts remain addressable before synthesis.

Build a retention metric over deposited branches: count seeded attempts, count those still findable by ID and relation, and count those that can still influence synthesis after a delay. A policy can then specify acceptable retention floors before recombination begins.

It proves that divergence is not only generation rate but preserved option value. It is falsified if retained counts do not predict later reuse or synthesis quality.
