# deposited-lineage

**What:** Divergent thought becomes evolutionary material only when it receives a durable ID, file, parent pointer, lens, obligations, and status.

Build this as the minimal deposit template for cycle outputs: every seed records where it came from, what lens produced it, what parent artifacts it descends from, and what future obligations it leaves active. Test it by giving fresh agents a deposited idea and a chat-only idea, then checking which one they can cite, modify, and recombine without recovering session context.

It proves that novelty needs a lineage carrier before it can enter the repository's germline. It is weakened if chat-only ideas are just as recoverable and usable after context reset.
