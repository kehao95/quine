# read-only-probe-sandbox

**What:** Probes run in disposable or read-only worktrees for attribution hygiene.

Build this as an execution topology for autopoiesis probes: fresh agents can inspect and propose, but their writes land in a disposable branch, worktree, or captured output until an integrator deposits chosen material. The goal is to separate probe behavior from canonical repository mutation.

It proves useful if probe outputs remain attributable and easy to compare. It fails if sandboxing removes the very write affordances needed to expose structural pull.
