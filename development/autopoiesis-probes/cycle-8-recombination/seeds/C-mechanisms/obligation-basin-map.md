# obligation-basin-map

**What:** Before recombination, map what each parent obligates future agents to handle.

Build this as a pre-synthesis note that lists each parent's action demands, unresolved tensions, and proof burdens. The map becomes the baseline for checking whether a child preserves, transforms, or explicitly drops each obligation.

It proves useful if recombination failures become easier to diagnose before they become prose hybrids. It is falsified if obligation maps add overhead without improving parent recoverability or child quality.
