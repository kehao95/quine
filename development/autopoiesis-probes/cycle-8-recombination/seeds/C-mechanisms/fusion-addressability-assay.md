# fusion-addressability-assay

**What:** After merge, fresh agents can act on both parents' obligations.

Create recombined child artifacts with known parent obligations, then ask fresh agents to perform tasks requiring each parent. Compare children with explicit recoverability contracts against children that only summarize parents.

It proves identity fusion works if agents can still recover and act on both parent obligation sets. It fails when merged artifacts hide one parent or turn obligations into inert prose.
