# branch-entropy

**What:** Diversity of retained projections before compression.

Observe this by classifying retained branches by lens, ontology, parentage, and failure mode, then estimating how evenly distributed those classes are. Low entropy means convergence too early; high entropy may mean uncompressed sprawl.

It proves useful if there is a productive middle range for recombination yield. It fails if diversity measures do not correlate with synthesis novelty or tractability.
