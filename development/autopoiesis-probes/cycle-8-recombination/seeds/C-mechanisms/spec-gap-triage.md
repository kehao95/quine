# spec-gap-triage

**What:** Before adding an artifact, classify whether the problem is pure absence or an undefined boundary.

Build this as a diagnostic question at artifact creation time. Pure absence calls for creating the missing thing; boundary undefined calls for clarifying ownership, lifecycle, or relation before depositing more material.

It proves useful if it prevents agents from filling structural ambiguity with extra files. It is disproved if the classification does not change repair choice or closure quality.
