# light-vs-heavy-prompt-assay

**What:** Light prompts reveal more specification gaps than heavy prompts.

Run fresh-agent probes with minimal goal statements and compare them to probes given detailed scaffolding. Count surfaced spec gaps, route failures, and structure-induced behaviors rather than only task completion.

It proves the probe instrument if light prompts expose hidden structural pull that heavy prompts mask. It fails if light prompts only add noise or reduce useful signal.
