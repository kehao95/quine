# hybrid-viability-boundary

**What:** A hybrid stays fit if it remains inside viability constraints and preserves addressability.

Observe this by checking both sides of recombination: the child must remain usable within current repository procedures and must preserve durable access to parent obligations. Failures outside either side mark the viability boundary.

It proves useful as an operational fitness definition for hybrids. It fails if viable-looking hybrids still decay or if boundary violations produce valuable future structure.
