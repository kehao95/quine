# commutator-friction

**What:** Two valid repairs do not commute, revealing a missing dimension.

Observe this by applying repair A then B and comparing it with B then A. If both repairs are locally valid but produce incompatible endpoints, the system likely lacks a dimension or relation that would make their interaction explicit.

It proves useful as a validator-quality signal because non-commutation exposes hidden coupling. It is weakened when order differences are only implementation noise rather than structural information.
