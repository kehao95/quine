# versioned-concept-fragments

**What:** A single file carries explicitly separated readings such as geometry and practice projections.

Build this as the lighter competitor to projection-object: one concept file contains named projection sections, each with its own claims, tensions, and evidence hooks. Use it when the overhead of separate projection files may exceed the benefit.

It tests whether disciplined internal sectioning is enough to preserve multiple readings. It is disproved when edits to one projection repeatedly blur or overwrite obligations in another.
