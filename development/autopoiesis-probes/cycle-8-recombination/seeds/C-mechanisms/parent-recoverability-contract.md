# parent-recoverability-contract

**What:** A child must state how each parent's obligations can still be acted on.

Build this as a validity condition for recombined artifacts. For every parent, the child records the preserved obligation, where it now lives, and the action a future agent can still take because of it.

It proves that integration is not valid if it erases parent affordances. It fails if a child can be useful while making parent obligations unrecoverable, or if the contract becomes boilerplate that agents ignore.
