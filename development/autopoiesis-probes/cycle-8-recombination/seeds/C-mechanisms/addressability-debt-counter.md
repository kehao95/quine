# addressability-debt-counter

**What:** Count insights that are mentioned but not filed or linked.

Build this as a debt counter over syntheses, chats, probe outputs, and notes. Every insight without a durable ID, file, or incoming link is debt because it cannot reliably enter later recombination.

It proves useful if reducing addressability debt increases reuse. It fails if unfiled mentions are still recoverable enough or if filing them creates more noise than value.
