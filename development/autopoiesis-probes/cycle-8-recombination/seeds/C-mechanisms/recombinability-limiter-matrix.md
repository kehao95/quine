# recombinability-limiter-matrix

**What:** Yield is jointly limited by complementarity and addressability.

Run a 2x2 test across high/low complementarity and high/low addressability parent sets. Compare whether high yield requires both dimensions rather than either one alone.

It proves the limiter matrix if complementary but unaddressable parents and addressable but redundant parents both underperform. It fails if one dimension dominates or if the interaction is not observable.
