# narrative-hybrid-control-assay

**What:** A prose summary underperforms a functional relation graph.

Run a control assay where one condition receives a narrative synthesis of parents and another receives explicit parent edges, obligations, child axis, and validation plan. Fresh agents then use each artifact for downstream theory or discovery tasks.

It proves that recombination needs functional structure if the graph condition produces better reuse and fewer lost obligations. It fails if prose summaries perform as well.
