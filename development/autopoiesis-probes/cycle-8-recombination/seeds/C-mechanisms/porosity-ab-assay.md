# porosity-ab-assay

**What:** Rigid-gated, open, and seed-labeled surfaces differ in yield and noise.

Run an A/B/C assay across three intake designs: strict promotion gates, fully open deposit, and lightweight seed labels with later promotion. Measure accepted novelty, search noise, reuse, and repair cost.

It proves membrane design matters if seed-labeled porosity captures novelty without the overload of fully open intake. It is falsified if all designs converge on similar yield/noise tradeoffs.
