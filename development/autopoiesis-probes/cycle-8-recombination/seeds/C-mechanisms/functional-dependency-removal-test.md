# functional-dependency-removal-test

**What:** Removing a real child artifact impairs future agents.

Run downstream tasks with a recombined child artifact present, then remove or hide it and rerun with comparable fresh agents. Measure changes in route choice, correctness, parent obligation recovery, and synthesis quality.

It validates use rather than elegance if removal measurably harms future work. It fails if the artifact can be removed with no behavioral loss.
