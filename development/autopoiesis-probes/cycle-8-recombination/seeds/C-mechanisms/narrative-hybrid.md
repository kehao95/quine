# narrative-hybrid

**What:** A child sounds like its parents but preserves no obligations.

Detect this by checking whether a synthesized artifact can name actionable inherited obligations from each parent. If it only echoes vocabulary or writes a smoother story, it is a narrative hybrid rather than a functional recombination.

It proves useful as a failure-mode detector at promotion time. It fails if obligation preservation is too strict for valid abstraction or if agents can use narrative hybrids productively anyway.
