# synthesis-before-refutation-assay

**What:** Synthesis-first produces more novelty than refutation-first.

Compare two ordering regimes for the same divergent material. One asks agents to synthesize before auditing; the other asks them to refute or judge material before synthesis. Measure novelty, obligation preservation, and later validation success.

It proves order matters if synthesis-first retains valuable tensions that refutation-first suppresses. It fails if refutation-first improves quality without lowering novelty.
