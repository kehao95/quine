# projection-drift-sensor

**What:** Docs and indexes diverge from capabilities in a machine-sensible way.

Build this as a sensor that compares projected claims against current files, validators, and executable affordances. Drift appears when an index says an object exists, a procedure is active, or a capability is available but the substrate disagrees.

It proves useful if projection drift becomes visible before human correction. It fails if the sensor mostly flags stale prose that has no behavioral consequence.
