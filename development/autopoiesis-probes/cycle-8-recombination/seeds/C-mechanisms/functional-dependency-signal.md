# functional-dependency-signal

**What:** Downstream agents actually depend on a child structure.

Observe this by tracing whether fresh agents cite, traverse, edit, or rely on a recombined artifact when completing later tasks. Dependency is stronger when removing the artifact measurably degrades behavior.

It proves that usefulness is behavioral rather than aesthetic. It fails if agent dependence reflects prompt bias or discoverability alone rather than real structural value.
