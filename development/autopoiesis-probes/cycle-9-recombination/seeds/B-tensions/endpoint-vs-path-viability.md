# endpoint-vs-path-viability

## Tension

Two repair orders may reach coherent-looking final files while differing in
whether the repository remained viable at every intermediate state. Endpoint
equivalence treats temporary incoherence as acceptable if final closure works;
path viability asks whether a dead interval followed by reconstruction is still
the same self-maintaining lineage.

The conflict is between repair-as-result and repair-as-continuous survival.

## What it would take to resolve later

A later test would need intermediate-state checkpoints: fresh-agent reachability,
sensor continuity, ownership legibility, and validation behavior after each
operation, not only at the final endpoint.
