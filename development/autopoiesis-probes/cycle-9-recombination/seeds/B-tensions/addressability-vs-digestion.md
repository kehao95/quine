# addressability-vs-digestion

## Tension

Depositing a seed into an addressable file creates a genotype-like carrier for
future recombination. But addressability is not digestion: a written artifact may
not yet shape future-agent behavior, validation, closure, or theory growth.

The paradox is that decomposition requires deposited lineages, while autopoietic
incorporation requires those lineages to become metabolically available.

## What it would take to resolve later

A later test would need to ask whether future agents actually find, use, and act
through the deposited seed without root data-piping. Incorporation would be shown
by changed repair choices or theory growth, not file existence alone.
