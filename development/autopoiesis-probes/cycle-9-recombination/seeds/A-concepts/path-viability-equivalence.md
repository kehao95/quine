# path-viability-equivalence

Two repair orders may count as equivalent under one reading and divergent under another. Byte diff, graph shape, validator state, paper-claim boundary, navigation reachability, intermediate viability, and future-agent competence may define different equivalence classes.

This seed names the missing comparison layer for commutator-friction. It does not decide which equivalence should dominate; it preserves the possibility that equality itself is path-relative and task-relative.
