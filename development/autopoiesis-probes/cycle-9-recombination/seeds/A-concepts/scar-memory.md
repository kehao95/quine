# scar-memory

Order-sensitive residue may be scar tissue: added routing, exception language, duplicate surfaces, or defensive checks that preserve a history of prior boundary failure. Scar is not automatically debt, because some scars may carry useful immune memory.

This concept keeps cleanup and memory in tension without resolving them. It asks how a repository distinguishes useless compensatory complexity from a path-formed structure that helps future agents avoid reopening the same wound.
