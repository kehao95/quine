# sequence-carrier-topology

Repair order may itself be a carrier of repository state. What survives is not only the endpoint artifact, but the sequence of openings, handoffs, checks, scars, navigation windows, and future-agent affordances through which the endpoint became reachable.

This seed should stay under-defined for now. It names the possibility that ordered operations have topology: paths can converge, twist, branch, narrow, or preserve latent structure that no single repair contains alone.
