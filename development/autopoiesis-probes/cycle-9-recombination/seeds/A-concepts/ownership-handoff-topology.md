# ownership-handoff-topology

Ownership is not only an endpoint label. A repair sequence can move the judging organ before, during, or after the content it will judge, producing different closure paths even when the final canonical location looks correct.

This seed names the topology of handoff: which owner receives the artifact, which owner judges the transition, which navigation path future agents inherit, and which old owner continues to exert path gravity after the move.
