# path-viability-equivalence-vector

**What:**

A mechanism seed for comparing repair orders across multiple equivalence classes: byte diff, validator state, ownership graph, fresh-agent route, evidence preservation, and intermediate viability. The candidate mechanism is that commutator friction often appears nonzero in one equivalence class and near-zero in another.

The useful object is the vector of residues, not a scalar score. A path can commute under final validator state while failing under future-agent reachability, or diverge textually while preserving the same ownership topology.
