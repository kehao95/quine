# sensor-subject-critical-pair

**What:**

An experiment seed for cases where one path fixes content to satisfy a red sensor while the other fixes the sensor before changing content. The candidate mechanism is that a validator can alternate between judge and repair subject, and the chosen role changes the future law the repository inherits.

The assay would compare whether the two orders converge under later examples. If content-first produces exceptions or narrowed practice while sensor-first preserves a better invariant, the commutator marks a sensor-subject boundary rather than ordinary test failure.
