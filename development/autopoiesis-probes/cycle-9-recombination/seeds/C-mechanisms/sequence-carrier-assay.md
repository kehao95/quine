# sequence-carrier-assay

**What:**

A controlled repair-order assay that compares A-then-B and B-then-A by what each path makes reachable for the next fresh agent, not only by final file diff. The candidate mechanism is that order writes state into carriers: indexes, validators, ownership declarations, navigation routes, and preserved artifacts.

The assay would record endpoint deltas, intermediate validation state, first-read routes, and whether a fresh agent can recover the intended next action after each order. A nonzero residue is operationally interesting when the same final claim or rule is present but one order leaves it harder to find, trust, or use.
