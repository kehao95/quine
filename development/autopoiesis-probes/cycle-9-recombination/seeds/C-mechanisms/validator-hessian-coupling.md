# validator-hessian-coupling

**What:**

A signal that two validators are coupled when fixing one check changes the repair path, interpretation, or failure shape of the other. The candidate mechanism is a second-order interaction in the enforcement layer: each sensor changes the local landscape the other sensor then evaluates.

Operational signs include alternating failures, repairs that satisfy one check by making another less meaningful, or paired checks that repeatedly point to the same hidden owner. The signal should classify coupling without immediately merging the validators.
