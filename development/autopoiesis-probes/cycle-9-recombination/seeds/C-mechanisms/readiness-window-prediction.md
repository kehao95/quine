# readiness-window-prediction

**What:**

Candidate prediction: repair orders that close a surface before routing the next perturbation will produce more follow-on friction than orders that leave an explicit readiness window. The expected residue is not immediate red validation, but later hesitation, duplicated routing, or agent uncertainty about where the next change belongs.

This is a seed-level prediction only. A future formal test could compare matched repairs where one order finalizes closure first and the other records the next admissible perturbation before closure.
