# absorption-lag-assay

**What:**

An assay for repairs or seeds that are written but not yet metabolized into future behavior. The candidate mechanism is that deposition, assimilation, and reproductive availability are distinct stages, and B can fail after A because A is addressable but not digested.

The assay would ask a later fresh agent to use A without extra prompt scaffolding, then compare whether B becomes easier, unchanged, or distorted. If the file exists but does not change agent action, the residue is absorption lag rather than absence.
