# Cycle-10 Compression

## Decision

Promote one concept now:
[`metabolic-transition-topology`](../../../Paper/theory/objects/metabolic-transition-topology.md).

Retain all raw growth and seed files. Do not merge exact repeats. In this cycle,
exact repeated names are the strongest common-refinement evidence.

## Why This Promotion

`metabolic-transition-topology` survived all three projections:

- Topological / graph: the live unit is the transition among projections, not a
  projection node or consensus concept file.
- Autopoietic / metabolic: transitions must carry digestion state, because
  addressability without metabolic availability becomes sediment.
- Repository practice: transitions must carry future-agent affordance, because a
  substrate no agent can traverse is not an inheritance interface.

The promoted object is intentionally narrow. It does not absorb
`divergence-substrate`, `projection-object`, `quotient-digestion-debt`,
`manifest-as-membrane`, or the mechanism seeds. It only gives the primary child
dimension a stable address.
