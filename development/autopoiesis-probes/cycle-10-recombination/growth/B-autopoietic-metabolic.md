# B — Autopoietic / Metabolic Growth

## Lens Premise

The target is not primarily a storage problem. It is a metabolic boundary problem:
how can the repository ingest divergent readings of one latent concept without
either leaving them as inert residue or digesting them so quickly that their
projection-specific nutrients disappear?

From this lens, a projection-bearing substrate is an organ for delayed
assimilation. It deposits projection lineages inside the organism's membrane,
keeps them addressable as distinct material, and lets future agents metabolize
them when a later collision, gap, or repair path makes their difference useful.
The substrate is viable only if a projection can cross the fresh-agent barrier:
not merely be found, but become available to future action without root
data-piping or prompt memory.

## Growth

The filesystem's one-file-per-concept pull is a digestive enzyme. It turns
dispersed material into a coherent body by giving each concept an address, a
name, and a local maintenance surface. That enzyme is necessary: unaddressed
material cannot be inherited, recombined, assayed, or repaired. But the same
enzyme can over-digest divergence. A projection enters as a live lineage and
leaves as a consensus paragraph; the repository has preserved the nutrient
mass while killing the reproductive code.

The autopoietic question is therefore: what membrane lets the organism admit
foreign-internal difference? A divergent projection is not outside the repo like
an untracked thought, but it is also not yet part of the repo's unified theory
body. It is semi-assimilated material: inside the membrane, addressable by
future metabolism, but protected from immediate canonical collapse. This is a
different state from both archive and doctrine.

The membrane has to perform three jobs at once. First, it must preserve
lineage-specific identity: this reading came through this lens, with this
tension profile, and should remain citeable as itself. Second, it must bind that
lineage to the latent concept strongly enough that future agents can find it
when working on the concept. Third, it must keep the binding selectively
permeable, so relation to the shared concept does not imply subordination to a
single authoritative reading.

This reframes addressability. An address is not yet incorporation; it is a
genotype carrier. Digestion begins only when the projection changes a later
choice: a future agent selects it for collision, uses it to preserve a tension,
routes a repair differently, or recognizes a repeated over-flattening attempt as
an immune event. A projection-bearing substrate therefore needs metabolic
availability, not just search visibility. The question is not "can the file be
located?" but "does the organism know when this latent material is food?"

Absorption lag becomes positive rather than embarrassing. If every projection
must be absorbed immediately into the canonical object, the system has no
fermentation chamber: no place where partially digested difference can mature.
Lag protects combinatorial potential. It lets a projection remain live until
another lineage, anomaly, or repair problem makes it newly useful. But lag has a
half-life. If future agents cannot recover the projection without explicit
prompt scaffolding, the material is not fermenting; it is sediment.

Carrier succession is the organism's digestive tract. A projection may begin as
a growth file, reappear as a decomposed seed, become a typed edge, shape a
prediction, or enter a theory object as a preserved tension. Each carrier makes
different parts metabolically available. Raw growth preserves richness but is
harder to navigate. Seeds preserve addressable hooks but shed context. Theory
objects improve reachability but intensify the flattening enzyme. The substrate
has to let projections change carriers without lineage amnesia: the organism
must remember not only the latest compressed residue, but the fact that the
residue came from a partial projection that should not masquerade as the whole
latent concept.

This is where immune memory matters. A coherent repository needs defenses
against noise, duplication, and orphaned residue. But its immune system can also
mistake divergence for infection. The repeated impulse to clean up multiple
readings into one file is an autoimmune risk: the system attacks the variation
that makes future recombination possible. Projection-bearing substrate would
give the immune system a more specific memory: "this conflict has been admitted
as living divergence; do not resolve it merely because it appears as local
inconsistency." The immune memory is not a ban on compression. It is a marker
that compression must preserve the lineage of the tension it digests.

A projection becomes part of the organism when it can participate in metabolism
without being reintroduced by the original session. Stored residue is material
that exists but does not alter future viability. Incorporated projection is
material that future agents can inherit, collide, mutate, and recombine while
still recognizing the membrane around its partiality. The organism does not
become more coherent by eliminating all internal non-identity. It becomes more
viable when it can hold non-identity at the right membrane thickness: neither
unbounded swarm nor premature organ.

The open problem, under this lens, is a threshold problem. When does deposition
become digestion? When does digestion become flattening? When does preserved
divergence become pathological clutter? The projection-bearing substrate is the
missing metabolic middle: an addressable but not-yet-final carrier state where
future agents can inherit divergence as usable energy rather than as either
authoritative doctrine or forgotten residue.

## Tensions Preserved

- **Deposition versus digestion:** a projection needs an address before it can
  be inherited, but an address does not prove it has entered future behavior.
- **Membrane versus wall:** the substrate must protect projections from
  premature canonical collapse without isolating them so completely that they
  cannot recombine.
- **Immune defense versus autoimmune flattening:** the repository needs to
  reject noise and duplication, but it must not treat admitted divergence as a
  coherence violation merely because it resists one-file authority.
- **Absorption lag versus sediment:** delayed incorporation preserves
  recombination potential, yet indefinite lag becomes inert residue that burdens
  fresh-agent navigation.
- **Carrier succession versus lineage amnesia:** moving from growth file to seed
  to theory edge can increase reachability while erasing the projection-specific
  partiality that made the lineage valuable.
- **Organism coherence versus internal non-identity:** the snapshot stays one
  organism only if its divergent readings are bounded by a shared membrane, but
  it dies cognitively if coherence means all readings must agree.

## Candidate Child Dimensions

- **Projection membrane:** the semi-permeable boundary that binds a projection to
  a latent concept while preventing that relation from becoming immediate
  authority or merger.
- **Metabolic addressability:** the difference between searchable deposition and
  future-action availability; a projection is metabolically addressable only when
  later agents can find the moment where it matters.
- **Absorption-lag viability window:** the interval in which a deposited lineage
  is neither inert residue nor over-digested consensus, but retained as live
  recombinable material.
- **Carrier-succession lineage memory:** the preservation of projection-specific
  origin, partiality, and lost context as material moves across growth files,
  seeds, edges, predictions, and theory objects.
- **Divergence immune memory:** a repository-level memory that a named tension is
  admitted living divergence, so future cleanup does not misread it as accidental
  inconsistency.
- **Organism-membership threshold:** the point at which a projection stops being
  stored residue and starts participating in the repository's self-maintaining
  metabolism.

## Seeds To Decompose Later

- `projection-membrane`: What exact boundary condition lets one latent concept
  host multiple projections without assigning any one projection the status of
  the concept itself?
- `metabolic-addressability`: When does an address become actionable nutrition
  for future agents rather than an inert coordinate in the repository?
- `absorption-lag-viability-window`: How long can a lineage remain partially
  digested before its preserved openness stops helping recombination and starts
  increasing entropy?
- `carrier-succession-lineage-memory`: What must survive each carrier transition
  so a later compressed residue still inherits the projection's partiality and
  tension profile?
- `divergence-immune-memory`: How can the system remember that a conflict is an
  admitted divergence, not a defect to be normalized away?
- `organism-membership-threshold`: What observable change shows that a projection
  has become part of the organism rather than merely stored inside it?
