# Obstruction Immune Memory

## Tension

Failed gluing can be meaningful structure: a named obstruction that prevents a
false global reading. It can also be immune memory against cleanup that would
mistake admitted divergence for accidental inconsistency. But obstruction can
degenerate into conflict hoarding, where every mismatch is preserved as a virtue
and digestion is avoided by status-labeling the refusal.

The substrate needs to remember failed gluing without making non-resolution the
goal. Conflict must stay testable rather than decorative.

## What it would take to resolve later

Resolution would require an obstruction form that names what still blocks gluing,
what evidence could dissolve it, and when preservation has become avoidance.
