# Fresh-Agent Transition Assay

The practical test of a projection-bearing substrate is not whether projection files exist or whether an index points to them. It is whether a later agent acts through projection transitions instead of asking which file is canonical.

An assay would look for changed repair behavior: the agent finds multiple readings as intended, knows which transition is safe to traverse, preserves named conflict, chooses collision or decomposition when appropriate, and routes compression back to raw lineages rather than replacing them.

This seed keeps the theory honest because it binds topology and metabolism to observable repository behavior. A transition topology that does not change fresh-agent motion is only a decorative graph.
