# Claim Inheritance Leak

Projection identity needs inheritance, but the wrong inheritance flattens divergence. A projection should inherit address, lineage, boundary conditions, sibling comparability, and non-erasure obligations. It should not automatically inherit the parent concept's claims.

Claim-inheritance leak is the failure where shared identity starts behaving like conceptual authority. The projection becomes a descendant in name but is contaminated by the current best reading before its own partiality has done work.

## What it would take to resolve later

Resolve by distinguishing lineage inheritance from claim inheritance in a way future agents can follow. The concept is live if it prevents a projection from being corrected toward parent doctrine merely because it shares the parent address.
