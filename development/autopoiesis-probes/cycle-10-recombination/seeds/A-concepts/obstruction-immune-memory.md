# Obstruction Immune Memory

Failed gluing can be theoretical material rather than a defect to smooth away. A persistent mismatch between projections may mark a real obstruction: a reason no global reading should yet exist.

The metabolic version of this is immune memory. The repository needs to remember that some conflicts have been admitted as living divergence, so future cleanup does not treat them as accidental inconsistency. But immune memory can decay into obstruction hoarding, where every unresolved mismatch becomes proof that digestion should never happen.

## What it would take to resolve later

Resolve by separating productive failed gluing from cleanup avoidance. A useful obstruction should remain testable: future agents should be able to ask whether it still blocks gluing, what would dissolve it, and what recombination it protects in the meantime.
